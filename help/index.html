1. Introduction

Home Gallery (家相簿) is an Android photo and video manager for on-device media and home storage (NAS / PC over SMB). You choose the space—no extra cloud capacity to buy. Use the disks you already have; photos stay in storage you control.

  • Browse and manage photos and videos in the local gallery
  • Connect home albums to shared folders on a NAS / PC (each card is one host + one share + one folder)
  • Register SMB credentials once under Host connections in Settings (scan once, sign in once, reuse later)
  • View, edit, share, copy, move, rename, and delete photos
  • Slideshow auto-plays selected photos (local / home albums; Pro can also cast the slideshow to a TV)
  • Bookmark frequently used folders
  • Browse a local timeline; browse home media by date with the home-album timeline
  • Home videos can stream on the phone (no full-file download first)
  • UI languages: English, Traditional Chinese, Simplified Chinese, Japanese, Korean (follows system language)

This app does not host a cloud gallery. SMB passwords stay on your device. Basic is a full, ad-free photo manager (slideshow, home video streaming, timelines, recycle bin, parallel folders, manual album backup, browse backup zone, and more). Pro (optional, one-time purchase) additionally unlocks automatic album backup and photo / slideshow casting to a TV.

Requirements: Android 11 (API 30) or later.

2. Getting started

2.1 Opening the app

The app opens in the local gallery. If photo access is not granted yet, allow Photos and videos.

2.2 Main navigation (bottom bar)

A bottom navigation bar switches the main areas (in landscape it becomes a side rail with the same items). There are four tabs:

TabWhat it does
LocalOn-device gallery (folders / timeline). With the recycle bin enabled, open it from the local gallery title bar
HomeOpens your last home album; tap again to open / close the album picker (switch albums, manage home albums)
BookmarksOpens / closes the bookmark panel: folder bookmarks and video bookmarks; tap to jump or resume
MoreMenu: Album backup (if disabled, goes to the Settings toggle; if enabled, opens backup and may show pending / failed badges), Settings, About

There is no sidebar. There is also no “network storage” connection list; home files are always opened from the Home tab.
About (rate / share / version) is under More → About; Settings → Support can open it too. Upgrade to Pro and report a problem are also in Settings.

Second tap on Home / Bookmarks: if you are already on that tab, tapping the same icon toggles the picker panel without leaving what you are browsing.

During multi-select or in the viewer / player, the bottom bar may hide and return when you go back to browsing.

2.3 Leaving the app

On main screens such as the local gallery, a home album, or Settings, the first Back press shows “Press Back again to exit”; press again within 2 seconds to close the app.

3. Local gallery

3.1 Browsing photos

  • The root shows folders (for example DCIM, Pictures)
  • Open a folder to see a grid of photos
  • Tap a photo for full-screen viewing
  • With the recycle bin enabled: the title bar opens the recycle bin (a count badge appears when it has items; Basic and Pro can enable this in Settings)

3.2 Search and sort

  • Use the top search field to search by file name; the X on the right clears text when present, or closes search when empty
  • Tap sort to change the field (name, modified date, capture date, size, folder) and ascending / descending

3.3 Multi-select

  1. Long-press a photo / video to enter selection; at the folder root, long-press a folder to select all media inside
  2. Tap other items to add them (in folder mode you can also tap a folder to toggle selecting the whole folder)
  3. Range select: while already selecting, long-press another item (or folder) to select everything between them (inclusive) in the current browse order; the anchor is the last tap or long-press that entered selection
  4. The bottom toolbar shows: Slideshow, Copy, Move, Delete, Share, Upload to home album
  5. After deleting a whole folder’s media in folder mode, if the path has no files left, the app tries to remove the empty folder (it will not delete system roots such as DCIM / Pictures; folders that still contain non-media files are kept)

Slideshow: after multi-select, tap Slideshow to auto-play the selected photos (videos are skipped). See §5.8.

3.4 Bookmarks

Tap the bookmark icon in the gallery toolbar to bookmark the current folder; open it later from the Bookmarks tab.

3.5 Browse modes

At the local gallery root, switch views in the toolbar:

ModeWhat you see
FoldersBrowse by folder (default); root shows folders, then a photo / video grid
TimelineAll media newest-first by capture date, grouped by day in a grid

Timeline:

  • Bottom date axis: year / month / day granularity; pinch to change it, or tap “year / month / day” in the hint
  • At day granularity the axis shows thumbnails; labels are the date (in Chinese locales M月d日) and year
  • A fast scroller on the right (when there is enough content) jumps quickly
  • Search, multi-select, the viewer, and video playback are supported

Shared:

  • Bookmarks still point at a folder path; opening a bookmark returns to folder mode

Settings → Local gallery → Grid display sets the default browse mode (folders / timeline) and default sort; the app also remembers the last mode you used.

4. Home albums and SMB hosts

Haven’t shared a folder on your PC / NAS yet? Start with the standalone setup guide:
Set up home storage (Windows 11 · Synology · QNAP; if you cannot connect see Troubleshooting; away NAS see WebDAV; away Windows / no WebDAV see Tailscale).

ConceptMeaning
SMB hostOne NAS / PC plus credentials (registered under Settings → Host connections)

4.1 Add an SMB host

  1. Open More → Settings → Host connections → Manage host connections
  2. Tap Add SMB host (or “Find a new SMB host” in the home-album flow)
  3. The dialog scans the LAN and asks you to confirm Wi‑Fi is on and on the same network as the storage
  4. Pick a host (already-saved hosts are dimmed) → enter credentials; a host name is used as the display name when available → Test connection → Save
    • LAN IPv4: for home Wi‑Fi (for example 192.168.x.x)
    • Remote access (optional, see §4.4):
      • WebDAV: for a NAS while away; enter external host (DDNS / public IP) and HTTPS port (often 5006)
      • Tailscale: for Windows or when WebDAV is unavailable; enter 100.x
      • None: home LAN only, no away helper
  5. You can also type a host address manually

Connection notes (in Settings)

  • Home albums are meant for the same home Wi‑Fi (LAN); at home the app uses SMB
  • On mobile data away from home:
    • NAS: prefer WebDAV (DDNS / public IP); see the WebDAV guide
    • Windows PC or no WebDAV: use Tailscale or an existing LAN VPN; see the Tailscale guide
  • The UI may show “home LAN” or “away”; away mode still needs WebDAV, Tailscale, or a VPN configured correctly
  • The connection notes card on Manage host connections opens the online WebDAV / Tailscale setup pages
  • Enable IPv6 (same page, off by default): when off, discovery and connect use IPv4 only and IPv6 fields are hidden; saved IPv6 is kept. Turn it on to scan / use IPv6. Away, use WebDAV / Tailscale (see §4.4)

4.2 Add a home album

  1. Bottom navigation → Home (if you have no albums yet, setup is offered; or tap Home again → Manage home albums)
  2. If there is no album yet, tap Connect home storage (or the Add FAB)
  3. If there is no host yet: the Add SMB host dialog opens; after you save, setup continues
  4. If hosts already exist:
    • One host: go straight to Choose a share
    • Several hosts: pick a host, then a share
    • Find a new SMB host is available when you need a scan
  5. Choose the album folder: browse subfolders in the share; you can stop at any level as the album root
  6. Display name (optional) defaults to the folder name → tap Done (this creates one album)
  7. Open it from the Home tab; tap Home again to switch albums

Setup no longer re-runs a full host scan or lets you multi-select several shares to create many albums in one go.

4.3 Browse and manage

  1. Bottom navigation → Home → open an album (or tap Home again and switch in the picker)
  2. Browse that source folder (grid / list)
  3. The title bar switches Folders / Timeline. Timeline shows photos and videos by date across folders (Basic). The first open builds an index; later visits prefer the cache. If the index is older than about 24 hours it refreshes silently after connect; you can also refresh manually. On the timeline, pull down to refresh folders near the current view (segment refresh) without a full-library rescan
  4. Switching to timeline inside a subfolder shows only that folder’s scope
  5. Tap a photo to view; the toolbar can Refresh. After a rename on the timeline, the index follows the new name; a later move uses the new path
  6. Timeline multi-select can align times (match a reference photo) or correct time on a single photo (date and time)
  7. On the home-album manage screen, each album has a timeline scan depth (1–8 levels, default 4; the album root is level 0)

Remove an album link

  • On the home-album manage screen: long-press a card or tap ⋮ → Remove album link
  • This only removes the link in the app; it does not delete files on the storage device

Multi-select move / copy

  • The destination picker lists home albums by display name only (no second-line path), then you can enter subfolders

4.4 Away access (optional)

After you leave home Wi‑Fi, pick one remote method for the host type:

Host typeRemote accessNotes
NAS (HTTPS WebDAV enabled)WebDAVDDNS / public IP + port; see WebDAV guide
Windows PC / no WebDAVTailscaleEnter 100.x; see below and Tailscale guide
Already on the LAN via OpenVPN etc.None (or keep the LAN address)Usually no extra WebDAV / Tailscale

WebDAV (recommended for NAS)

  1. On home Wi‑Fi, set up the host and home album first (§4.1–4.2)
  2. Enable WebDAV HTTPS on the NAS and prepare DDNS or a public IP
  3. Edit the host → Remote access = WebDAV → enter external host and port → Test connection → Save
  4. (Most home NAS use a self-signed certificate) You may enable Allow untrusted HTTPS certificates: the app tries system trust first; if that fails it pins the certificate for that host (TOFU)—the first successful connection stores the fingerprint. If the NAS certificate changes later and connection fails, turn this option off and on again to re-pin
  5. Open the home album while away (turn off home Wi‑Fi to verify)

Full steps and security notes: WebDAV guide.

Tailscale (Windows / no WebDAV)

Use Tailscale as a secure tunnel so the phone can reach home SMB at 100.x.

Short flow:

  1. On home Wi‑Fi, set up the host and home album first (§4.1–4.2)
  2. PC / NAS: install Tailscale → sign in → Connected → copy that machine’s Tailscale IPv4 (100.x)
  3. Phone: install Tailscale → same account → Connected
  4. Open the home album while away → when prompted Open Tailscale → copy the PC 100.x → return to the app → Paste → Save Tailscale IP and retry

Day to day: open Tailscale when you need the album. When you leave the app or return to home Wi‑Fi, the app asks Tailscale to disconnect to save power. If you already have OpenVPN (or similar) onto the LAN, you usually do not need Tailscale.

Full walkthrough, FAQ, and notes: Tailscale guide.

Enable IPv6 (optional)

Under Host connections you can toggle Enable IPv6 (off by default):

  • Off: discovery and connect stay IPv4-only; IPv6 fields are hidden when editing; saved IPv6 is kept
  • On: the app can scan / fill IPv6 and use it among connection candidates
  • For away access use WebDAV / Tailscale in §4.4

9.7 Album backup

Album backup uploads one way from the local gallery into a private zone on home storage (.HomeGallery/backup/{device}/) so you can restore after a phone failure.

Each device keeps device_info.json in its own folder (model, optional display name, last backup time). When several people share the same backup anchor, set Local backup identity → Display name in album backup settings; the “Link existing backup” list shows that name / model instead of only android_xxxx.

If you switch to another share, change host, or change the backup anchor folder, local tracking starts over: synced / failed / backup-only counts clear. Tap Check pending backup to scan again (if the new destination already has a backup for this device, items can align as synced without a full re-upload).

Unlike Basic “upload to a public folder”, the backup zone is app-managed, hidden from normal network browsing by default, and keeps the local copy by default.

Browse backup zone (large folder grid)

  1. More → Album backup → Browse backup zone
  2. Open the private backup root in home-album folder mode (large grid); drill into folders as needed
  3. Backup-only items have a red border; long-press to select and purge them from the backup zone (and drop tracking)
  4. Files that exist on the backup disk but have no local index row are labeled Not tracked (often copied in manually, or after an index reset); run a scan / remote index before they appear as Backup-only
  5. List-style restore / filters still use View backup / restore below

Restore (R1.1)

  1. More → Album backup (or Album backup in Settings) → View backup / restore
  2. Default filter Missing on device (backed up before, gone locally; not items in the recycle bin, and not permanent deletes from this app)
  3. Tap Restore all missing, or multi-select then Restore selected → confirm (file count, size, path-mapping count) → restore (Items after linking an old phone are usually “Backup only”; the Missing-on-device filter also shows those pending files)
  4. Restored files appear in the local gallery

Parallel-folder restore paths (important)

If the backup contains parallel paths such as Documents/…:

ConditionWhere restore writes
Without SAF for that parallel pathMapped to Pictures/{original relative path} (for example Documents/Office Lens/a.jpg → Pictures/Documents/Office Lens/a.jpg; videos may map under Movies/…)

If the confirm dialog shows path mapping, some files will land under Pictures. Device-to-device restore (R2) uses the same rule.

New phone (R2) (link existing backup / full restore library; Basic and Pro)

  1. More → Album backup → View backup / restore
  2. Tap Link existing backup → pick the old phone’s backup/{deviceId}/ on the NAS (restore source only)
  3. After indexing, use the Backup only filter for files not on this phone
  4. Multi-select or Restore all missing (same parallel-folder rule: without SAF they go to Pictures/…)
  5. Later backups from this phone still write to its own folder; the old phone can keep backing up separately

After clearing app storage (same phone)

  1. After a backup, Export settings first (this also remembers the backup deviceId)
  2. Clear app storage (or reinstall) → grant permissions again → Restore settings as soon as possible (do not enable album backup first, or a new device identity may be created)
  3. Open album backup → Check pending backup: the app connects to the home backup zone and marks local files that still match the NAS as synced—no full re-upload
  4. If you restore settings on another phone that already has a different identity: the write identity stays; the imported old deviceId is treated as a linked restore source (use “Link existing backup” to index / restore)
  5. If the export is old (no deviceId), export again after a backup, or pick the old folder with “Link existing backup”

10. FAQ

Q1: Local photos are missing?

  • Confirm Photos and videos access is granted
  • Settings → Local gallery folders: make sure the folder is in Include folders

Q2: Cannot connect to home storage?

  • Phone and NAS / PC must be on the same home Wi‑Fi / LAN
  • Settings → Host connections: check address, account, and password
  • Confirm SMB is enabled on the NAS / PC (port 445)
  • If scan finds nothing: turn Wi‑Fi on, stay on the same LAN as the storage, then scan again
  • Cannot connect while away:
    • NAS: remote access must be WebDAV, with the correct DDNS / port → WebDAV guide
    • Windows / no WebDAV: see the Tailscale guide
    • Other cases: Troubleshooting §E

Q3: A system permission prompt appears when deleting or editing a local photo?

On Android 11+, some media created by other apps needs an extra grant to modify / delete. Allow it in the system dialog.

Q4: Portrait / smooth looks weak?

  • Confirm a face was detected, or drag the circle and resize it with the slider
  • Raise Smooth
  • Apply (✓) then Save

Q5: Quality drops after editing?

Portrait preview uses a lower resolution for speed; Save processes at original resolution. If it still looks too strong, lower Smooth.

Q6: Copy / upload to a home album is slow?

Speed depends on network bandwidth and file size. Use a stable Wi‑Fi connection.

Q7: Why can I view SVG but not edit it?

SVG is vector. The app can only view a rasterized bitmap, not edit vectors and save SVG, so Edit is hidden. See §5.6.

Q8: Why is there no Edit button for GIF / HEIC?

Those formats can be viewed, but an edited save cannot keep the original format (GIF animation, HEIC encoding). To avoid damage, Edit is only for .jpg, .jpeg, .png, .webp.

Q9: An SVG file is missing from the local gallery?

Confirm Android MediaStore indexed it (Downloads is a common case). If the system never registered the SVG as media, this app cannot list it.

Q10: A video is listed but will not play?

  • Confirm the extension is in §5.7
  • On the phone: the app tries the built-in engines (Media3 or the compatibility engine); if that fails, open with another app. You can also test the same file in another player
  • Network video: check the network; if needed, clear cache in Settings and retry

12.5 Pro FAQ

Q: Can Basic edit, delete, and upload?

Yes. Basic is a full photo manager, not a view-only app.

Q: Do local or home videos require Pro?

No. Local and home video playback are Basic. Pro unlocks automatic album backup and photo cast.

Q: Does photo cast to a TV require Pro?

Yes. Basic can play a slideshow on the phone; TV cast needs Pro. Video Cast remains Basic.

Q: Why does video cast say “bitrate too high”?

Only when transcode is required but there is no local file or transcode cache yet. Typical phone H.264 casts directly and is not blocked by bitrate. HEVC and other TV-incompatible codecs are prepared first. See §5.7.

Q: How is upload different from backup?

Upload is you picking files and a home album folder (Basic and Pro). With the recycle bin on, a fully successful upload can move local copies to the bin to save space. Backup writes the local gallery one way into an app-managed private backup zone and keeps local copies by default; restore in the app when you need it.

Q: How does album backup differ between Basic and Pro?

Basic supports manual backup, exclude folders, and restore / linking an old phone. Pro can additionally enable automatic background backup on Wi‑Fi.

Q: Is backup two-way?

No. Backup is phone → NAS. Editing backup files on the NAS does not write back to the phone. Restore is a deliberate action in the app.

Q: Office Lens files live in Documents. Can Basic see them?

Yes. Basic and Pro can Select and authorize parallel folders such as Documents under Settings → Local gallery.

Q: When restoring, where do Documents and other parallel folders go?

Without SAF for that folder: a mapped path under Pictures/ (not back to Documents/…). With that parallel folder authorized: the original relative path. The restore confirm dialog shows how many paths are mapped. See §9.7.

Q: Why is “Use this folder” grey when authorizing Download?

This is an Android 11+ system limit. The app cannot get a tree grant for the Download root. Choose Documents, or authorize a subfolder under Downloads. The app does not offer a “read-only include Download” path (it would disagree with copy / restore writes and be more awkward).

1. 簡介

Home Gallery（家相簿）是一款 Android 相片與影片管理應用程式，讓您同時管理手機本機與家中儲存（NAS／PC，透過 SMB 連線）上的相片與影片。空間自己決定，不必為雲端加購容量——用家裡已有的硬碟擴充，照片留在您掌控的空間。

  • 瀏覽與管理本機相簿中的相片與影片
  • 以 家中相簿 連線家中 NAS／PC 的共用資料夾（每張卡片對應「一台主機 + 一個 share + 一個資料夾」）
  • 在設定中以 主機連線管理 統一登記 SMB 主機帳密（掃一次、登入一次，之後沿用）
  • 檢視、編輯、分享、複製、移動、重新命名與刪除相片
  • 投影片自動播放選取的相片（本機／家中相簿；Pro 可同時投影到電視）
  • 將常用目錄加入書籤快速存取
  • 本機時間軸瀏覽；家中相簿時間軸依日期瀏覽家中媒體
  • 家中影片可在手機串流播放（無需先整檔下載）
  • 介面語言：英文、繁體中文、简体中文、日本語、한국어（隨系統語言）

本 App 不提供雲端相簿代管服務；SMB 帳密僅保存在您的裝置上。Basic 為無廣告的完整相片管理器（含投影片、家中影片串流、時間軸、回收桶、平行目錄、手動相簿備份與瀏覽備份區等）；Pro（選購、一次性購買）額外解鎖相簿備份自動同步，以及將相片／投影片投影到電視。

系統需求：Android 11（API 30）或以上。

4. 家中相簿與 SMB 主機

還沒在電腦／NAS 開過共用？ 請先看獨立建置指南：
家中儲存建置指南（Windows 11 · Synology · QNAP；連不上見 排查；外出 NAS見 WebDAV；外出 Windows／無 WebDAV見 Tailscale）。

家中檔案以兩層概念管理：

概念說明
SMB 主機一台 NAS／PC + 帳密（在設定 主機連線管理 登記）
家中相簿一張卡片 = 選定主機下的一個共用資料夾（share）＋其中一個資料夾路徑

4.1 新增 SMB 主機

  1. 開啟 更多 → 設定 → 主機連線管理 → 管理主機連線
  2. 點 新增 SMB 主機（或家中相簿流程中的「尋找新的 SMB 主機」）
  3. 對話框會掃描區域網路，並提示確認 Wi‑Fi 已開啟且與儲存裝置同一區網
  4. 選取主機（已登記者會灰顯）→ 輸入帳密；若有主機名稱會帶入顯示名稱 → 測試連線 → 儲存
    • 區網 IPv4：家中 Wi‑Fi 用（如 192.168.x.x）
    • 遠端存取（選用，見 §4.4）：
      • WebDAV：NAS 外出用；填 外網主機（DDNS／公網 IP） 與 HTTPS 埠（常見 5006）
      • Tailscale：Windows 或無法開 WebDAV 時；填 100.x
      • 無：只在家中區網使用，不啟用外出輔助
  5. 亦可改手動輸入主機位址

連線說明（設定內）

  • 家中相簿以同一家中 Wi‑Fi（區網）使用為主；在家時走 SMB
  • 外出改用行動數據時：
    • NAS：建議用 WebDAV（DDNS／公網 IP），見 WebDAV 使用手冊
    • Windows PC 或無 WebDAV：用 Tailscale 或既有家中區網 VPN，見 Tailscale 使用手冊
  • 畫面可能顯示「家中區網」或「外網」；外網模式仍須你已正確設定 WebDAV 或 Tailscale（或 VPN）才可能連上
  • 管理主機連線頁的「連線說明」卡片可直接開啟線上 WebDAV／Tailscale 建置頁
  • 啟用 IPv6（同頁開關，預設關閉）：關閉時探索與連線僅用 IPv4，並隱藏 IPv6 欄位；已儲存的 IPv6 不會清除。開啟後才會掃描／使用 IPv6。外出請用 WebDAV／Tailscale（見 §4.4）

4.2 新增家中相簿

  1. 底部導航 → 家中（若尚無相簿會引導新增；或再開一次 家中 開啟相簿選擇器 → 管理家中相簿）
  2. 若尚無相簿，點 連線家中儲存（或 FAB 新增）
  3. 若尚無主機：自動開啟「新增 SMB 主機」對話框；儲存後進入後續步驟
  4. 若已有主機：
    • 僅一台：直接進入 選擇共用資料夾（share）
    • 多台：先選主機，再選 share

4.4 外出連線（選用）

WebDAV（NAS 建議）

  1. 家中 Wi‑Fi 先把主機與家中相簿設好（§4.1～4.2）
  2. NAS 啟用 WebDAV HTTPS，並準備 DDNS 或公網 IP
  3. 編輯主機 → 遠端存取 = WebDAV → 填外網主機與埠 → 測試連線 → 儲存
  4. （多數家用 NAS 為自簽憑證）可勾選 允許不受信任的 HTTPS 憑證：App 會先套用系統信任；失敗時才對該主機做憑證釘選（TOFU）——第一次成功連線會記住憑證指紋。若 NAS 之後換憑證而無法連線，請關閉再開此開關以重新釘選
  5. 外出開啟家中相簿即可（關家中 Wi‑Fi 驗證）

完整步驟與安全提醒：WebDAV 使用手冊。

Tailscale（Windows／無 WebDAV）

可用 Tailscale 當安全隧道，讓手機以 100.x 連回家中 SMB。

精簡流程：

  1. 家中 Wi‑Fi 先把主機與家中相簿設好（§4.1～4.2）
  2. PC／NAS：安裝 Tailscale → 登入 → Connected → 複製該機的 Tailscale IPv4（100.x）
  3. 手機：安裝 Tailscale → 同一帳號 → Connected
  4. 外出開啟家中相簿 → App 提示時 開啟 Tailscale → 複製 PC 的 100.x → 返回 App → 貼上 → 儲存 Tailscale IP 並重試

日常： 要看相簿再開 Tailscale；離開 App 或回到家中 Wi‑Fi 時，App 會請 Tailscale 斷線以省電。若你已有 OpenVPN 等連進區網，通常不必再開 Tailscale。

完整圖文步驟、FAQ 與注意事項：Tailscale 使用手冊。

10. 常見問題（FAQ）

Q1：看不到本機相片？

  • 確認已授予「相片和影片」讀取權限
  • 至設定 → 本機相簿目錄，確認相片所在目錄已加入「包含目錄」

Q2：無法連線家中儲存？

  • 確認手機與 NAS／PC 在同一家中 Wi‑Fi／區域網路
  • 至設定 → 主機連線管理 確認主機位址、帳號、密碼正確
  • 確認 NAS／PC 的 SMB 服務已啟用（port 445）
  • 若掃描不到主機：確認 Wi‑Fi 已開啟，並與儲存裝置同一區網後重新掃描
  • 外出連不上：
    • NAS：確認遠端存取為 WebDAV，且 DDNS／埠正確 → WebDAV 手冊
    • Windows／無 WebDAV：見 Tailscale 手冊
    • 其餘排查：排查 §E

Q3：刪除或修改本機相片時出現系統授權提示？

Android 11 以上對部分由其他 App 建立的媒體，修改/刪除需額外授權。請在系統對話框中允許。

Q4：肖像／柔膚效果不明顯？

  • 確認已偵測到人臉，或已手動拖曳圓形並用滑桿調整大小
  • 調高「柔膚」強度
  • 套用（✓）後再儲存

Q5：編輯後相片品質下降？

肖像預覽為加速而降低解析度；儲存時使用原圖解析度處理。若仍不滿意，請降低柔膚強度。

Q6：複製／上傳到家中相簿很慢？

速度取決於網路頻寬與檔案大小。建議在穩定的 Wi-Fi 環境下操作。

Q7：為什麼 SVG 看得到但不能編輯？

SVG 為向量格式，App 僅能光柵化後瀏覽，無法以向量方式編輯並存回 SVG。因此瀏覽頁會隱藏編輯按鈕。詳見 §5.6。

Q8：為什麼 GIF / HEIC 沒有編輯按鈕？

這些格式雖可瀏覽，但儲存編輯結果時無法維持原格式（例如 GIF 動畫、HEIC 編碼）。為避免檔案損壞，App 僅對 .jpg、.jpeg、.png、.webp 提供編輯功能。

Q9：本機相簿找不到 SVG 檔？

請確認檔案已被 Android MediaStore 索引（常見於「下載」等目錄）。若系統未將 SVG 登錄為媒體檔，本 App 無法列出該檔案。

Q10：影片有列出但無法播放？

  • 確認副檔名在 §5.7 所列格式內
  • 手機無法播：App 會先嘗試內建引擎（Media3 或相容引擎）；仍失敗時可用「其他應用程式」開啟。亦可改用其他 App 測試同一檔案
  • 網路影片：確認網路穩定，必要時至設定清除快取後重試

12.5 常見問題

Q：Basic 能編輯、刪除、上傳嗎？

可以。Basic 是完整的相片管理器，不是只能看的 Viewer。

Q：本機影片或家中影片要 Pro 嗎？

不需要。本機與家中影片播放皆屬 Basic；Pro 解鎖相簿備份自動同步與相片投影。

Q：相片投影到電視要 Pro 嗎？

要。Basic 可在手機播放投影片；投到電視需 Pro。影片 Cast 仍屬 Basic。

Q：為什麼影片投影提示「位元率過高」？

只在需要先轉檔、但家中還沒有本機檔或轉檔快取時。常見手機 H.264 是直接投影，不會因碼率被擋。HEVC 等電視解不了的會先準備再投。詳見 §5.7。

Q：上傳和備份有什麼不同？

上傳是您手動選檔、選家中相簿目錄（Basic／Pro 皆可）。若已開啟回收桶，上傳全部成功後可選擇將本機副本移至回收桶以省空間。備份是將本機相簿單向寫入 App 管理的私有備份區，預設不刪本機；需要時在 App 內手動還原。

Q：Basic 和 Pro 的相簿備份差在哪？

Basic 支援手動備份、排除目錄、還原／連結舊機。升級 Pro 後可額外啟用 Wi‑Fi 自動背景備份。

Q：備份會雙向同步嗎？

不會。備份是本機 → NAS；在 NAS 上改備份檔不會自動寫回手機。還原需您在 App 內主動操作。

Q：Office Lens 在 Documents 裡，Basic 看得到嗎？

可以。Basic 與 Pro 皆可在設定 → 本機相簿中選取並授權 Documents 等平行資料夾，納入掃描範圍。

Q：從備份還原時，Documents 等平行目錄會還原到哪裡？

尚未 SAF 授權該資料夾時：寫入 Pictures/ 下的映射路徑（不會寫回原 Documents/…）。已授權該平行資料夾時：可寫回原本相對路徑。還原確認對話框會顯示路徑映射筆數。詳見 §9.7。

Q：為什麼授權 Download／下載 時「使用這個資料夾」是灰色的？

這是 Android 11 以後的系統限制，App 無法對下載根目錄取得資料夾樹授權。請改選 Documents，或在下載底下對子資料夾授權。本 App 不另提供「只讀納入 Download」（與複製／還原等寫入行為不一致，操作更煩瑣）。

1. はじめに

ホームギャラリー（家相簿）は、Android用の写真・動画管理アプリで、デバイス内のメディアや家庭内ストレージ（NAS / SMB経由でPC）に対応しています。スペースは自分で選べます—追加のクラウド容量を購入する必要はありません。 既に持っているディスクを使い、写真は自分が管理するストレージに保存されます。

  • ローカルギャラリーで写真や動画を閲覧・管理
  • ホームアルバムを共有フォルダーに接続する（各カードは1つのホスト＋1つの共有＋1つのフォルダー）
  • 設定の Host connections で SMB の資格情報を一度登録する（一度スキャンして、一度サインインし、後で再利用）
  • 写真を表示、編集、共有、コピー、移動、名前変更、削除する
  • スライドショー は選択した写真（ローカル / ホームアルバム）を自動再生します；Pro はスライドショーをテレビにキャストすることもできます
  • よく使うフォルダーをブックマークする
  • ローカルのタイムラインを閲覧する；ホームアルバムタイムラインで日付ごとにホームメディアを閲覧する
  • ホームビデオは電話でストリーミングできます（最初にファイル全体をダウンロードする必要はありません）
  • UI言語: 英語、繁体字中国語、簡体字中国語、日本語、韓国語（システム言語に従う）

このアプリはクラウドギャラリーをホストしません。SMB のパスワードはデバイスに保存されます。Basic は完全で広告のない写真管理アプリです（スライドショー、ホームビデオストリーミング、タイムライン、ごみ箱、並行フォルダ、手動アルバムバックアップ、バックアップゾーンの閲覧など）。Pro（任意、一度きりの購入）では、さらに自動アルバムバックアップおよびTVへの写真／スライドショーキャストが解除されます。

要件: Android 11 (API 30) 以上。

2.1 アプリを開く

アプリはローカルギャラリーで開きます。まだ写真へのアクセスが許可されていない場合は、写真と動画を許可してください。

ホーム最後に開いたホームアルバムを開きます；もう一度タップすると アルバムピッカー を開く／閉じる（アルバムの切り替え、ホームアルバムの管理）

3. 地元のギャラリー

3.1 写真の閲覧

  • ルートはフォルダー（例えば DCIM、Pictures）を表示します
  • フォルダーを開いて写真のグリッドを表示する
  • 写真をタップして全画面表示
  • ごみ箱が有効になっている場合: タイトルバーを開くとごみ箱が開きます（アイテムがあるとカウントバッジが表示されます; Basic と Pro は設定でこれを有効化できます）

3.2 検索と並べ替え

  • 上の検索フィールドを使ってファイル名で検索します；右側のXはテキストがある場合はクリアし、空の場合は検索を閉じます
  • 並べ替えをタップして、フィールド（名前、変更日、撮影日、サイズ、フォルダ）および昇順／降順を変更します

3.3 複数選択

  1. 写真や動画を長押しして選択モードに入ります。フォルダのルートでは、フォルダを長押しすると内部のすべてのメディアを選択できます。
  2. 他のアイテムをタップして追加します（フォルダモードでは、フォルダ全体を選択するかどうかを切り替えるためにフォルダをタップすることもできます）
  3. 範囲選択: すでに選択している状態で、別の項目（またはフォルダ）を長押しすると、現在の閲覧順でその間のすべての項目（含む）が選択されます。アンカーは、選択を開始した最後のタップまたは長押しです。
  4. 下部ツールバーには以下が表示されます：スライドショー、コピー、移動、削除、共有、ホームアルバムにアップロード
  5. フォルダモードでフォルダ内のメディアをすべて削除した後、パスにファイルが残っていない場合、アプリは空のフォルダを削除しようとします（DCIM / Pictures のようなシステムルートは削除されません。メディア以外のファイルを含むフォルダは保持されます）

スライドショー: 複数選択の後、選択した写真を自動再生するにはスライドショーをタップします（動画はスキップされます）。§5.8を参照してください。

3.4 ブックマーク

ギャラリーツールバーのブックマークアイコンをタップして、現在のフォルダーをブックマークします。後でブックマークタブから開くことができます。

3.5 ブラウズモード

地元のギャラリー root では、ツールバーで表示を切り替えます:

モード表示される内容
フォルダーフォルダーごとに閲覧（デフォルト）；ルートはまずフォルダーを表示し、その後に写真/ビデオのグリッドを表示
タイムラインすべてのメディアを 撮影日 順（最新が先）で、日ごとにグリッド表示

タイムライン：

  • 下の日付軸: 年／月／日単位；ピンチして変更するか、ヒントの「年／月／日」をタップしてください
  • 日単位の粒度では、軸にはサムネイルが表示されます；ラベルは日付（中国語のロケールでは M月d日）と年です
  • 右側の高速スクロールバー（コンテンツが十分にある場合）は素早くジャンプします
  • 検索、複数選択、ビューア、およびビデオ再生がサポートされています

共有:

  • ブックマークはまだフォルダのパスを指しています；ブックマークを開くとフォルダモードに戻ります

設定 → ローカルギャラリー → グリッド表示 は、デフォルトの閲覧モード（フォルダー / タイムライン）とデフォルトの並べ替えを設定します。アプリは最後に使用したモードも記憶します。

4. ホームアルバムとSMBホスト

PCやNASでフォルダーをまだ共有していませんか？ スタンドアロンのセットアップガイドから始めましょう:
Set up home storage (Windows 11 · Synology · QNAP; 接続できない場合は Troubleshooting を参照; 離れて NAS は WebDAV を参照; 離れて Windows / WebDAV がない場合 は Tailscale を参照).

ホームファイルは2つの層を使用します:

コンセプト意味
SMB ホスト1 NAS / PC と資格情報（設定 → ホスト接続 に登録済み）
ホームアルバム1枚のカード = そのホスト上の1つのシェア + その中の1つのフォルダパス

4.1 SMB ホストを追加

  1. その他 → 設定 → ホスト接続 → ホスト接続の管理 を開きます
  2. SMBホストを追加をタップ（またはホームアルバムのフローでは「新しいSMBホストを探す」）
  3. ダイアログはLANをスキャンし、あなたにWi‑Fiがオンであり、ストレージと同じネットワーク上にあることを確認するよう求めます
  4. ホストを選択（すでに保存されているホストは薄く表示されます）→ 資格情報を入力；ホスト名は利用可能な場合、表示名として使用されます → 接続をテスト → 保存
  5. LAN IPv4: 家庭用 Wi‑Fi（例えば 192.168.x.x）
  6. リモートアクセス（任意、§4.4参照）：
  7. WebDAV: NAS の間離れている場合；外部ホスト (DDNS / 公開IP) と HTTPS ポート を入力（多くの場合 5006）
  8. Tailscale: Windows用、またはWebDAVが利用できない場合; 100.xを入力してください
  9. なし: ホームLANのみ、外部ヘルパーなし
  10. ホストアドレスを手動で入力することもできます

接続のメモ（設定内）

  • ホームアルバムは 同じホーム Wi‑Fi（LAN） 用です；自宅ではアプリは SMB を使用します
  • 外出先でモバイルデータを使用する場合:
  • NAS: WebDAV を好む (DDNS / 公共IP); WebDAV guide を参照
  • Windows PC またはなし WebDAV: Tailscale または既存の LAN VPN を使用; Tailscale guide を参照
  • UIには「ホームLAN」や「外出中」と表示されることがあります。外出中モードでも、WebDAV、Tailscale、またはVPNが正しく設定されている必要があります。
  • 「接続ノート」カードは、ホスト接続の管理でオンラインの WebDAV / Tailscale 設定ページを開きます
  • Enable IPv6(同じページ、デフォルトでオフ):オフ時はDiscovery and ConnectがIPv4のみを使用し、IPv6フィールドは非表示;保存されたIPv6は保持されます。オンにしてスキャン/IPv6を使用します。AwayはWebDAV / Tailscale(§4.4参照)を使用。

4.2 ホームアルバムを追加する

  1. 下部ナビゲーション → ホーム（アルバムがまだない場合、設定が提案されます；または再度 ホーム をタップ → ホームアルバムを管理）
  2. まだアルバムがない場合は、ホームストレージに接続（または 追加 FAB）をタップします
  3. まだホストがいない場合: 「ホストを追加 SMB」ダイアログが開きます。保存後、セットアップが続行されます
  4. 既にホストが存在する場合：
  5. 1つのホスト：共有を選択 に進む
  6. 複数のホスト：ホストを選択してから、共有を選択
  7. 新しいSMBホストを見つける はスキャンが必要なときに利用可能です
  8. アルバムのフォルダーを選択: 共有内のサブフォルダーを参照します; アルバムのルートで任意のレベルで停止できます
  9. 表示名（任意） はフォルダ名がデフォルト → 完了 をタップ（これで 1つ のアルバムが作成されます）
  10. ホームタブから開きます；アルバムを切り替えるには再度ホームをタップします

＞ セットアップは もう フルホストスキャンを再実行したり、複数の共有を一度に選択して多くのアルバムを作成したりすることはできません。

4.3 閲覧と管理

  1. 下部ナビゲーション → ホーム → アルバムを開く（または ホーム を再度タップしてピッカーで切り替える）
  2. そのソースフォルダーを閲覧する（グリッド / リスト）
  3. タイトルバーは フォルダ / タイムライン を切り替えます。タイムラインはフォルダを横断して日付ごとに写真や動画を表示します（Basic）。初めて開くとインデックスが作成され、後の訪問ではキャッシュが優先されます。インデックスが約24時間以上古い場合、接続後に自動的に静かに更新されます。また、手動で更新することもできます。タイムライン上では、現在表示されている付近のフォルダを更新するために 下に引き下げる（セグメント更新）ことができ、ライブラリ全体の再スキャンは不要です。
  4. サブフォルダ内でタイムラインに切り替えると、そのフォルダの範囲のみが表示されます
  5. 写真をタップして表示します。ツールバーで更新できます。タイムラインで名前を変更した後、インデックスは新しい名前に従います。その後の移動では新しいパスが使用されます
  6. タイムラインのマルチセレクトは、時間を揃える（参照写真と一致させる）ことや、単一の写真の時間を修正する（日付と時刻）ことができます
  7. ホームアルバムの管理画面では、各アルバムにタイムラインスキャン深度（1～8レベル、デフォルトは4；アルバムのルートはレベル0）があります

アルバムのリンクを削除する

  • ホームアルバムの管理画面で：カードを長押しするか ⋮ をタップ → アルバムリンクを削除
  • これはアプリ内のリンクのみを削除します；ストレージデバイス上のファイルは削除されません

複数選択して移動／コピー

  • 宛先ピッカーはホームアルバムを表示名のみで一覧表示します（2行目のパスは表示されません）、その後サブフォルダを入力できます

WebDAV（NASに推奨）

  1. ホームWi‑Fiで、まずホストとホームアルバムを設定する（§4.1–4.2）
  2. NASでWebDAV HTTPSを有効にし、DDNSまたはパブリックIPを準備します
  3. ホストを編集 → リモートアクセス = WebDAV → 外部ホストとポートを入力 → 接続をテスト → 保存
  4. （ほとんどの家庭用NASは自己署名証明書を使用しています）信頼されていないHTTPS証明書を許可を有効にすることができます：アプリはまずシステムの信頼を試みます；それが失敗した場合、そのホストの証明書をピン留めします（TOFU）—最初の接続に成功した時にフィンガープリントが保存されます。後でNAS証明書が変更されて接続に失敗した場合は、このオプションを一度オフにしてから再度オンにしてピンを再設定してください
  5. 不在時にホームアルバムを開く（確認のためホームWi‑Fiをオフにする）

完全な手順とセキュリティに関する注意事項: WebDAV guide。

Tailscale（Windows / WebDAVなし）

Tailscale を安全なトンネルとして使用し、携帯電話が 100.x で自宅 SMB に接続できるようにします。

短いフロー:

  1. ホームWi‑Fiで、まずホストとホームアルバムを設定する（§4.1–4.2）
  2. PC / NAS: Tailscale をインストール → サインイン → 接続済み → そのマシンの Tailscale IPv4 (100.x) をコピー
  3. 電話: インストール Tailscale → 同じアカウント → 接続済み
  4. 外出中にホームアルバムを開く → プロンプトが表示されたら 開くTailscale → PCの100.xをコピー → アプリに戻る → 貼り付け → Tailscale IPを保存して再試行

日常的な使い方: アルバムが必要なときにTailscaleを開きます。アプリを離れるかホームに戻るとWi‑Fi、アプリは電力を節約するためにTailscaleの切断を求めます。すでにLANにOpenVPN（または同様のもの）がある場合、通常はTailscaleは必要ありません。

完全なウォークスルー、FAQ、ノート：Tailscale guide。

IPv6 を有効にする（オプション）

ホスト接続の下で、有効化 IPv6（デフォルトではオフ）を切り替えることができます：

  • オフ: 発見と接続はIPv4のみ; 編集時にIPv6フィールドは非表示; 保存されたIPv6は保持される
  • オン: アプリはIPv6をスキャン/入力でき、接続候補間で使用できます
  • 遠隔アクセスには §4.4 の WebDAV / Tailscale を使用してください

10. よくある質問

Q1: ローカルの写真が見つかりませんか？

  • 写真とビデオへのアクセスが許可されていることを確認する
  • 設定 → ローカルギャラリーフォルダー：フォルダーが フォルダーに含める にあることを確認してください

Q2: ホームストレージに接続できませんか？

  • 携帯電話とNAS/ PCは同じ家庭用Wi‑Fi/ LANに接続されている必要があります
  • 設定 → ホスト接続：アドレス、アカウント、パスワードを確認
  • NAS / PC（ポート445）でSMBが有効になっていることを確認してください
  • スキャンで何も見つからない場合：Wi‑Fi をオンにし、ストレージと同じLANに接続したまま、再度スキャンしてください
  • 離れている間は接続できません:
  • NAS: リモートアクセスは WebDAV である必要があり、正しい DDNS / ポート → WebDAV guide
  • Windows / なし WebDAV: Tailscale guide を参照
  • その他の場合: Troubleshooting §E

Q3: ローカルの写真を削除または編集する際にシステムの権限確認が表示されますか？

Android 11以上では、他のアプリによって作成された一部のメディアは変更や削除するために追加の権限が必要です。システムダイアログで許可してください。

Q4: ポートレート／スムーズは弱く見えますか？

  • 顔が検出されたことを確認するか、円をドラッグしてスライダーでサイズを変更してください
  • 滑らかさを上げる
  • 適用 (✓) してから保存

Q5: 編集後に品質は低下しますか？

ポートレートプレビューは速度のために低解像度を使用します；保存は元の解像度で処理します。まだ強すぎる場合は、スムーズを下げてください。

Q6: ホームアルバムへのコピー／アップロードは遅いですか？

速度はネットワーク帯域幅とファイルサイズに依存します。安定したWi‑Fi接続を使用してください。

Q7: なぜSVGは表示できるのに編集できないのですか？

SVGはベクターです。このアプリはベクターを編集してSVGとして保存することはできず、ラスター化されたビットマップのみを表示できます。そのため、編集は非表示になっています。§5.6を参照してください。

Q8: GIF / HEIC に編集ボタンがないのはなぜですか？

これらの形式は表示できますが、編集された保存では元の形式（GIFアニメーション、HEICエンコード）を保持できません。損傷を避けるため、編集は .jpg、.jpeg、.png、.webp のみに対応しています。

Q9: ローカルギャラリーにSVGファイルが見つかりませんか？

AndroidがMediaStoreをインデックスしたことを確認してください（Download秒は一般的なケースです）。システムがSVGをメディアとして登録していない場合、このアプリはそれを一覧表示できません。

Q10: 動画が表示されているが再生できませんか？

  • 拡張が§5.7にあることを確認してください
  • 電話で: アプリは組み込みエンジン（Media3 または互換性エンジン）を試します; それが失敗した場合、別のアプリで開きます。同じファイルを別のプレーヤーでテストすることもできます
  • ネットワークビデオ：ネットワークを確認してください。必要に応じて、設定でキャッシュをクリアして再試行してください

12.5 Pro よくある質問

Q: Basic は編集、削除、アップロードできますか？

はい。Basicは閲覧専用アプリではなく、完全な写真管理アプリです。

Q: ローカルまたはホームビデオにはProが必要ですか？

いいえ。ローカルおよびホームビデオの再生はBasicです。Proは自動アルバムバックアップとフォトキャストのロックを解除します。

Q: 写真をテレビにキャストするにはProが必要ですか？

はい。Basicは電話でスライドショーを再生できます；テレビキャストにはProが必要です。ビデオCastはBasicのままです。

Q: ビデオキャストで「ビットレートが高すぎます」と表示されるのはなぜですか？

トランスコードが必要だが、ローカルファイルやトランスコードキャッシュがまだ存在しない場合のみ。典型的な電話のH.264は直接キャストされ、ビットレートによってブロックされることはありません。HEVCや他のテレビ非対応コーデックは先に準備されます。§5.7を参照してください。

Q: アップロードはバックアップとどう違いますか？

アップロードとは、あなたがファイルとホームアルバムフォルダ（BasicとPro）を選ぶことです。ゴミ箱がオンの場合、完全に成功したアップロードはローカルのコピーをゴミ箱に移動してスペースを節約できます。バックアップはローカルギャラリーを一方向でアプリ管理のプライベートバックアップゾーンに書き込み、デフォルトでローカルコピーを保持します；必要なときにアプリで復元します。

Q: アルバムのバックアップはBasicとProでどのように異なりますか？

Basic は 手動 バックアップ、フォルダーの除外、旧端末の 復元 / リンクをサポートします。Pro はさらに Wi‑Fi で 自動 バックアップをバックグラウンドで有効にすることができます。

Q: バックアップは双方向ですか？

いいえ。バックアップは 電話 → NAS です。NAS 上のバックアップファイルを編集しても、電話には書き戻されません。復元はアプリでの意図的な操作です。

Q: Office LensのファイルはDocumentsに保存されます。Basicはそれを見ることができますか？

はい。Basic と Pro は、設定 → ローカルギャラリーで Documents のような並列フォルダーを 選択して承認 できます。

Q: 復元する際、Documentsや他の並列フォルダーはどこに行きますか？

そのフォルダーに対してSAFなし: Pictures/以下のマップされたパス（Documents/…には戻らない）。その並列フォルダーが許可されている場合: 元の相対パス。復元確認ダイアログには、何本のパスがマップされているかが表示されます。§9.7を参照してください。

Q: Downloadを認証するときに「このフォルダーを使用」がグレー表示になるのはなぜですか？

これはAndroid 11+ システム制限です。アプリはDownloadのルートに対してツリー権限を取得できません。Documentsを選択するか、Downloadの下にあるサブフォルダを認可してください。アプリは「読み取り専用でDownloadを含める」パスを提供していません（コピー／復元の書き込みと矛盾し、より扱いにくくなるためです）。

1. 소개

홈 갤러리 (家相簿)은 장치 내 미디어와 가정 저장소(NAS / SMB를 통한 PC)를 위한 안드로이드 사진 및 비디오 관리 앱입니다. 원하는 공간을 선택하세요—추가 클라우드 용량을 구매할 필요가 없습니다. 이미 가지고 있는 디스크를 사용하세요; 사진은 사용자가 제어하는 저장소에 남습니다.

  • 로컬 갤러리에서 사진과 동영상을 탐색하고 관리하세요
  • 홈 앨범을 NAS / PC의 공유 폴더에 연결하기 (각 카드에는 하나의 호스트 + 하나의 공유 + 하나의 폴더가 있음)
  • 설정의 호스트 연결에서 SMB 자격 증명을 한 번 등록하세요 (한 번 스캔하고, 한 번 로그인하면 나중에 재사용 가능)
  • 사진을 보고, 편집하고, 공유하고, 복사하고, 이동하고, 이름을 바꾸고, 삭제하세요
  • 슬라이드쇼는 선택된 사진(로컬 / 홈 앨범)을 자동 재생합니다; Pro는 슬라이드쇼를 TV로도 전송할 수 있습니다
  • 자주 사용하는 폴더를 즐겨찾기
  • 로컬 타임라인 탐색; 홈 앨범 타임라인으로 날짜별 홈 미디어 탐색
  • 가정용 비디오는 휴대폰에서 스트리밍할 수 있습니다 (전체 파일을 먼저 다운로드할 필요 없음)
  • UI 언어: 영어, 번체 중국어, 간체 중국어, 일본어, 한국어 (시스템 언어에 따름)

이 앱은 클라우드 갤러리를 호스팅하지 않습니다. SMB 비밀번호는 사용자의 기기에만 저장됩니다. Basic는 광고 없는 완전한 사진 관리 앱으로, 슬라이드쇼, 홈 비디오 스트리밍, 타임라인, 휴지통, 병렬 폴더, 수동 앨범 백업, 백업 영역 탐색, 그 외 기능들을 제공합니다. Pro (선택 사항, 일회성 구매)는 추가로 자동 앨범 백업과 사진/슬라이드쇼 TV 전송 기능을 잠금 해제합니다.

요구 사항: Android 11 (API 30) 이상.

2. 시작하기

2.1 앱 열기

앱이 로컬 갤러리에서 열립니다. 아직 사진 접근 권한이 허용되지 않았다면 사진 및 동영상을 허용하세요.

2.2 주요 내비게이션 (하단 바)

하단 내비게이션 바는 주요 영역을 전환합니다(가로 모드에서는 동일한 항목으로 측면 레일이 됩니다). 네 개의 탭이 있습니다:

탭기능
로컬기기 내 갤러리 (폴더 / 타임라인). 휴지통이 활성화된 경우, 로컬 갤러리 제목 표시줄에서 열기
홈마지막 홈 앨범을 엽니다; 다시 탭하면 앨범 선택기를 열거나 닫습니다 (앨범 전환, 홈 앨범 관리)
북마크북마크 패널 열기/닫기: 폴더 북마크 및 동영상 북마크; 탭하여 이동하거나 계속 재생
더보기메뉴: 앨범 백업 (비활성화된 경우 설정 토글로 이동; 활성화된 경우 백업을 열고 보류 중/실패 배지가 표시될 수 있음), 설정, 정보

사이드바가 없습니다. 또한 '네트워크 저장소' 연결 목록도 없으며, 홈 파일은 항상 홈 탭에서 열립니다.
정보(평가 / 공유 / 버전)는 더보기 → 정보에서 확인할 수 있으며; 설정 → 지원에서도 열 수 있습니다. Pro로 업그레이드하고 문제를 신고하는 것도 설정에 있습니다.

홈/북마크 두 번째 탭: 이미 해당 탭에 있는 경우, 같은 아이콘을 탭하면 현재 탐색 중인 내용을 벗어나지 않고 선택 패널이 토글됩니다.

멀티 선택 중이거나 뷰어/플레이어에서, 하단 바가 숨겨졌다가 탐색으로 돌아가면 다시 나타날 수 있습니다.

2.3 앱 종료

로컬 갤러리, 홈 앨범 또는 설정과 같은 주요 화면에서 처음 뒤로 버튼을 누르면 '다시 누르면 종료됩니다'가 표시됩니다. 2초 이내에 다시 누르면 앱이 종료됩니다.

3. 지역 갤러리

3.1 사진 탐색

  • 루트는 폴더(예: DCIM, Pictures)를 보여줍니다
  • 폴더를 열어 사진 그리드를 확인하세요
  • 사진을 전체 화면으로 보려면 탭하세요
  • 휴지통이 활성화된 경우: 제목 표시줄이 휴지통을 엽니다 (항목이 있을 때 카운트 배지가 나타납니다; Basic과 Pro은 설정에서 이를 활성화할 수 있습니다)

3.2 검색 및 정렬

  • 상단 검색 필드를 사용하여 파일 이름으로 검색합니다; 오른쪽의 X는 텍스트가 있을 때 지우거나, 비어 있을 때 검색을 종료합니다
  • 필드(이름, 수정 날짜, 캡처 날짜, 크기, 폴더) 및 오름차순/내림차순을 변경하려면 정렬을 탭하세요

3.3 다중 선택

  1. 사진/동영상을 길게 누르면 선택 모드로 들어갑니다; 폴더 루트에서는 폴더를 길게 눌러 안의 모든 미디어를 선택할 수 있습니다
  2. 다른 항목을 추가하려면 탭하세요 (폴더 모드에서는 폴더 전체를 선택하거나 해제하려면 폴더를 탭할 수도 있습니다)
  3. 범위 선택: 이미 선택 중인 상태에서, 다른 항목(또는 폴더)을 길게 누르면 현재 탐색 순서에서 그 사이의 모든 항목(포함)을 선택할 수 있습니다; 기준점은 선택에 들어간 마지막 탭이나 길게 누른 것입니다
  4. 하단 도구 모음에는 다음이 표시됩니다: 슬라이드쇼, 복사, 이동, 삭제, 공유, 홈 앨범에 업로드
  5. 폴더 모드에서 전체 폴더의 미디어를 삭제한 후, 경로에 파일이 남아 있지 않으면 앱이 빈 폴더를 제거하려고 시도합니다 (DCIM / Pictures과 같은 시스템 루트는 삭제되지 않으며; 미디어가 아닌 파일이 남아 있는 폴더는 유지됩니다)

슬라이드쇼: 다중 선택 후, 선택한 사진을 자동 재생하려면 슬라이드쇼를 탭하세요(비디오는 건너뜁니다). §5.8 참조.

3.4 즐겨찾기

갤러리 도구 모음에서 북마크 아이콘을 눌러 현재 폴더를 북마크하세요; 나중에 북마크 탭에서 열 수 있습니다.

3.5 탐색 모드

지역 갤러리 root에서 도구 모음의 보기를 전환하세요:

모드보이는 것
폴더폴더별 탐색(기본값); 루트는 먼저 폴더를 표시하고, 그 다음 사진/비디오 그리드를 표시
타임라인모든 미디어를 촬영 날짜 기준 최신순으로, 하루 단위로 그리드에 그룹화

타임라인:

  • 하단 날짜 축: 연도 / 월 / 일 단위; 확대/축소로 변경하거나 힌트에서 ‘연도 / 월 / 일’을 탭하세요
  • 일 단위 세분화에서는 축에 미리보기 이미지가 표시됩니다. 레이블은 날짜(중국어 로케일 M月d日에서)와 연도입니다.
  • 오른쪽에 빠른 스크롤러(콘텐츠가 충분할 때)가 빠르게 이동합니다
  • 검색, 다중 선택, 뷰어 및 동영상 재생이 지원됩니다

공유됨:

  • 즐겨찾기는 여전히 폴더 경로를 가리킵니다; 즐겨찾기를 열면 폴더 모드로 돌아갑니다

설정 → 로컬 갤러리 → 그리드 표시는 기본 탐색 모드(폴더 / 타임라인)와 기본 정렬을 설정하며, 앱은 마지막으로 사용한 모드도 기억합니다.

4. 홈 앨범과 SMB 호스트

PC / NAS에서 아직 폴더를 공유하지 않았나요? 독립 실행형 설정 가이드부터 시작하세요:
Set up home storage (Windows 11 · Synology · QNAP; 연결할 수 없으면 Troubleshooting 참조; 원격 NAS 참고 WebDAV; 원격 Windows / WebDAV 없음 참조 Tailscale).

홈 파일은 두 개의 레이어를 사용합니다:

개념의미
SMB 호스트하나의 NAS / PC 및 자격 증명 (설정 → 호스트 연결에 등록됨)
홈 앨범한 카드 = 해당 호스트의 한 개 공유 + 그 안의 한 폴더 경로

4.1 SMB 호스트 추가

  1. 더보기 → 설정 → 호스트 연결 → 호스트 연결 관리를 엽니다
  2. SMB 호스트 추가를 탭하세요(또는 홈 앨범 흐름에서는 “새 SMB 호스트 찾기”를 탭하세요)
  3. 대화 상자가 LAN을 스캔하고 Wi‑Fi이 켜져 있으며 스토리지와 동일한 네트워크에 있는지 확인하도록 요청합니다
  4. 호스트 선택(이미 저장된 호스트는 흐리게 표시됨) → 자격 증명 입력; 호스트 이름이 사용 가능할 때 표시 이름으로 사용됨 → 연결 테스트 → 저장
  5. LAN IPv4: 가정용 Wi‑Fi (예를 들어 192.168.x.x)
  6. 원격 접근 (선택 사항, §4.4 참조):
  7. WebDAV: 잠시 NAS 동안; 외부 호스트(DDNS / 공용 IP) 와 HTTPS 포트 입력 (보통 5006)
  8. Tailscale: Windows용 또는 WebDAV를 사용할 수 없을 때; 100.x를 입력하세요
  9. 없음: 집 LAN 전용, 외부 도움 없음
  10. 호스트 주소를 수동으로 입력할 수도 있습니다

연결 메모(설정에서)

  • 홈 앨범은 같은 집 Wi‑Fi (LAN)용입니다; 집에서는 앱이 SMB를 사용합니다
  • 집을 떠나 있을 때 모바일 데이터 사용:
  • NAS: WebDAV (DDNS / 공인 IP) 선호; WebDAV guide 참조
  • Windows PC 또는 없음 WebDAV: Tailscale 또는 기존 LAN VPN 사용; Tailscale guide 참조
  • UI는 '홈 LAN' 또는 '외출'을 표시할 수 있습니다; 외출 모드에서도 WebDAV, Tailscale 또는 올바르게 구성된 VPN이 필요합니다
  • 호스트 연결 관리에서 연결 메모 카드가 온라인 WebDAV / Tailscale 설정 페이지를 엽니다
  • IPv6 활성화 (같은 페이지, 기본값 끔): 끄면, 검색 및 연결은 IPv4만 사용하고 IPv6 필드는 숨겨집니다; 저장된 IPv6는 유지됩니다. 켜면 IPv6를 스캔 / 사용할 수 있습니다. 자리 비움 시, WebDAV / Tailscale를 사용하세요 (§4.4 참조)

4.2 홈 앨범 추가

  1. 하단 내비게이션 → 홈 (아직 앨범이 없으면 설정이 제공됩니다; 또는 홈을 다시 탭 → 홈 앨범 관리)
  2. 아직 앨범이 없다면, 홈 스토리지 연결(또는 추가 FAB)을 탭하세요
  3. 호스트가 아직 없는 경우: Add SMB 호스트 대화 상자가 열립니다; 저장 후 설정이 계속 진행됩니다
  4. 이미 호스트가 존재하는 경우:
  5. 한 호스트: 공유 선택으로 바로 이동
  6. 여러 호스트: 호스트를 선택한 다음 공유를 선택
  7. 스캔이 필요할 때 새 SMB 호스트 찾기 가능
  8. 앨범 폴더 선택: 공유 폴더 내의 하위 폴더를 탐색합니다; 앨범 루트에서 어느 수준에서든 멈출 수 있습니다
  9. 표시 이름(선택 사항)은 폴더 이름으로 기본 설정 → 완료를 탭합니다 (이렇게 하면 하나의 앨범이 생성됩니다)
  10. 홈 탭에서 열고; 앨범을 전환하려면 다시 홈을 탭하세요

설정은 더 이상 전체 호스트 검사를 다시 실행하지 않으며, 여러 공유를 다중 선택하여 한 번에 여러 앨범을 만들 수 없습니다.

4.3 찾아보고 관리하기

  1. 하단 내비게이션 → 홈 → 앨범 열기 (또는 홈을 다시 탭하고 선택기에서 전환)
  2. 해당 소스 폴더를 찾아보기(그리드 / 목록)
  3. 제목 표시줄은 폴더 / 타임라인을 전환합니다. 타임라인은 폴더별로 날짜별 사진과 동영상을 보여줍니다 (Basic). 첫 번째 열 때는 인덱스를 생성하며, 이후 방문에서는 캐시를 선호합니다. 인덱스가 약 24시간 이상 오래된 경우, 연결 후 조용히 새로 고침되며, 수동으로 새로 고침할 수도 있습니다. 타임라인에서 현재 보기에 가까운 폴더를 새로 고치려면 끌어당기기로 새로 고침(부분 새로 고침)을 할 수 있으며 전체 라이브러리 재스캔은 필요 없습니다.
  4. 하위 폴더 안에서 타임라인으로 전환하면 해당 폴더의 범위만 표시됩니다
  5. 사진을 탭하여 보기; 도구 모음에서 새로 고침할 수 있습니다. 타임라인에서 이름 변경 후, 인덱스는 새 이름을 따릅니다; 이후의 이동은 새 경로를 사용합니다
  6. 타임라인 다중 선택은 시간을 맞추거나 (참조 사진과 일치) 또는 단일 사진의 시간을 수정할 수 있습니다 (날짜와 시간)
  7. 홈 앨범 관리 화면에서 각 앨범은 타임라인 스캔 깊이(1–8 단계, 기본값 4; 앨범 루트는 0 단계)를 가집니다

앨범 링크 제거

  • 이것은 앱에서의 링크만 제거하며, 저장 장치의 파일을 삭제하지는 않습니다

WebDAV (NAS에게 추천됨)

  1. 홈 Wi‑Fi에서 먼저 호스트와 홈 앨범을 설정합니다 (§4.1–4.2)
  2. NAS에서 WebDAV HTTPS를 활성화하고 DDNS 또는 공인 IP를 준비합니다
  3. 호스트 편집 → 원격 액세스 = WebDAV → 외부 호스트와 포트 입력 → 연결 테스트 → 저장
  4. (대부분의 가정용 NAS은 자체 서명 인증서를 사용합니다) 신뢰할 수 없는 HTTPS 인증서 허용을 활성화할 수 있습니다: 앱은 먼저 시스템 신뢰를 시도합니다; 실패하면 해당 호스트에 대해 인증서를 고정(TOFU)합니다—첫 번째 성공적인 연결이 지문을 저장합니다. 나중에 NAS 인증서가 변경되어 연결이 실패하면, 이 옵션을 껐다가 다시 켜서 인증서를 다시 고정하십시오
  5. 집에 없을 때 홈 앨범 열기 (확인을 위해 홈 Wi‑Fi 끄기)

전체 단계 및 보안 참고 사항: WebDAV guide.

Tailscale (윈도우 / WebDAV 없음)

휴대폰이 100.x에서 집 SMB에 도달할 수 있도록 Tailscale을 안전한 터널로 사용하세요.

짧은 흐름:

  1. 홈 Wi‑Fi에서 먼저 호스트와 홈 앨범을 설정합니다 (§4.1–4.2)
  2. PC / NAS: Tailscale 설치 → 로그인 → 연결됨 → 그 컴퓨터의 Tailscale IPv4 (100.x) 복사
  3. 전화: 설치 Tailscale → 같은 계정 → 연결됨
  4. 집 앨범을 외출 중에 열기 → 메시지가 표시되면 Tailscale 열기 → PC 100.x 복사 → 앱으로 돌아가기 → 붙여넣기 → Tailscale IP 저장 후 재시도

일상: 앨범이 필요할 때 Tailscale을 엽니다. 앱을 나가거나 홈 화면으로 돌아가면 Wi‑Fi, 앱이 전력을 절약하기 위해 Tailscale 연결을 끊을지 묻습니다. 이미 LAN에 OpenVPN(또는 유사한 것)이 설치되어 있는 경우, 일반적으로 Tailscale이 필요하지 않습니다.

전체 안내, FAQ 및 노트: Tailscale guide.

IPv6 활성화 (선택 사항)

호스트 연결에서 활성화 IPv6(기본값은 꺼짐)을 전환할 수 있습니다:

  • 꺼짐: 발견 및 연결은 IPv4 전용; IPv6 필드는 편집 시 숨겨짐; 저장된 IPv6는 유지됨
  • 켜짐: 앱이 IPv6을 스캔/작성하고 연결 후보들 사이에서 사용할 수 있음
  • 원격 액세스를 위해 §4.4에서 WebDAV / Tailscale를 사용하십시오

Cast 비디오를 TV에

로컬 또는 홈 앨범에서 비디오를 Cast하는 것은 Basic입니다 (사진 캐스트는 §5.9). 전화기와 TV는 동일한 LAN에 있어야 합니다. 일부 확장 기능(예: .avi, .wmv)은 Cast 버튼을 숨깁니다.

코덱캐스팅 방식
H.264 / AVC (일반적인 휴대폰 MP4, 세로 모드 포함)직접 캐스트; 비트레이트나 세로 모드 때문에 트랜스코딩하지 않음
HEVC / H.265 및 기타 TV 비호환 코덱앱이 트랜스코딩을 수행합니다 ("비디오 캐스트 준비 중…"가 표시될 수 있음)

“이 비디오의 비트레이트가 너무 높습니다”라는 메시지는 트랜스코딩이 필요하지만 홈 파일이 다운로드되지 않았거나 트랜스코드 캐시가 없는 경우에만 나타납니다. 이로 인해 H.264가 차단되는 것은 아니라는 것이 확인되었습니다. 휴대폰에서 재생한 후, 로컬 파일이나 캐시가 존재하면 다시 캐스트를 시도하세요.

6. 사진 편집기

뷰어에서 편집을 탭하세요 (.jpg, .jpeg, .png, .webp만 이 버튼이 표시, §5.6 참고).

편집은 초안입니다. 두 개의 층이 있습니다:

  1. 도구 안에서 아래쪽(세로) 또는 오른쪽(가로)을 조정합니다; ✓를 눌러 해당 단계를 작업 미리보기에 적용하거나, X를 눌러 단계를 취소하고 도구 선택기로 돌아갑니다.
  2. 다시 도구 선택기로 돌아가서, 상단의 저장은 적용된 모든 단계를 파일에 기록합니다.

화면 방향: 세로 / 조정 / 자르기 모드로 들어가면 미리보기 공간을 위해 상단 제목 표시줄이 숨겨집니다; 시스템 뒤로 가기 버튼이나 툴바의 X를 누르면 해당 도구에서 나갑니다.

6.1 도구

세 가지 도구가 하단(세로) 또는 오른쪽(가로)에 나타납니다:

도구참고 사항
인물얼굴 매끄럽게 및 국소 색조 (밝기 / 대비 / 채도)
조정밝기, 대비, 채도, 색온도
자르기자르기, 기울이기, 회전 / 뒤집기

6.2 자르기

항목참고 사항
무료모서리와 가장자리를 자유롭게 끌기
원본현재 종횡비 잠금

  • 기울기: −15° ~ +15°, 눈금을 드래그; 초기화를 누르면 0으로 돌아갑니다
  • 자동: 제안된 기울기는 자동을 탭할 때만 계산됩니다 (자르기를 입력할 때는 아님)
  • 뒤집기 / 회전: 하단 확인 행 중간에 위치; 작업 중인 이미지에 즉시 적용됩니다 (이 자르기 단계를 확정하려면 나중에 ✓가 여전히 필요합니다)
  • 자르기 상자를 드래그하여 이동; 모서리를 드래그하여 크기 조절. 3등분 가이드선은 드래그하는 동안에만 나타납니다

6.3 조정

항목비고

  • 오른쪽의 재설정은 현재 항목을 재설정합니다
  • 회전/뒤집기에는 자르기(Crop)를 사용하세요
  • 단계 적용하려면 ✓을(를) 탭하세요

6.4 초상화

어두운 패널; 도구를 사용하면 얼굴을 감지합니다(‘다시 감지’할 수 있음). 확인 행이 전환됩니다: 부드럽게, 밝기, 대비, 채도.

제어참고
부드럽게강도 0–100; 얼굴이 있는 경우, 얼굴 크기에 따라 동적으로 제안됨 (약 20%–70%)
밝기 / 대비 / 채도얼굴에만 적용 (또는 수동 박스), 약 ±50%

얼굴을 찾을 수 없을 때:

  • 매끄러운 강도는 0%이며 제안이 표시되지 않습니다
  • 원형 영역이 나타납니다: 한 손가락으로 드래그하여 이동하고, 슬라이더로 크기를 조정한 후 부드럽게 올리세요

얼굴이 발견되었을 때:

  • 제안된 스무스는 가장 큰 얼굴이 프레임에서 차지하는 비율을 사용합니다 (가까운 샷은 더 높게, 그룹/멀리 있는 샷은 더 낮게) 그리고 '제안된 N%'를 표시합니다
  • 얼굴 윤곽이 그려져 있습니다

단계를 적용하려면 ✓를 탭하세요.

9. 설정

10. 자주 묻는 질문

Q1: 로컬 사진이 없나요?

  • 사진 및 동영상 접근 권한이 허용되었는지 확인
  • 설정 → 로컬 갤러리 폴더: 폴더가 포함된 폴더에 있는지 확인하세요

Q2: 집 저장소에 연결할 수 없나요?

  • 전화기와 NAS / PC는 동일한 집 Wi‑Fi / LAN에 있어야 합니다
  • 설정 → 호스트 연결: 주소, 계정, 비밀번호 확인
  • NAS / PC(포트 445)에서 SMB가 활성화되어 있는지 확인
  • 스캔에서 아무것도 발견되지 않으면: Wi‑Fi을 켜고 스토리지와 같은 LAN에 머문 후 다시 스캔하세요
  • 멀리 있을 때 연결할 수 없음:
  • NAS: 원격 액세스는 WebDAV 이어야 하며, 올바른 DDNS / 포트 → WebDAV guide
  • Windows / 없음 WebDAV: Tailscale guide을(를) 참조하세요
  • 기타 경우: Troubleshooting §E

Q3: 로컬 사진을 삭제하거나 편집할 때 시스템 권한 요청이 나타나나요?

Android 11+에서, 다른 앱에서 생성된 일부 미디어는 수정/삭제하려면 추가 권한이 필요합니다. 시스템 대화상자에서 허용하세요.

Q4: 초상화 / 매끈한 모습이 약해 보이나요?

  • 얼굴이 감지되었는지 확인하거나, 원을 끌어다 놓고 슬라이더로 크기를 조절하세요
  • 스무스 올리기
  • 적용 (✓) 후 저장

Q5: 편집 후 품질이 떨어지나요?

인물 미리보기는 속도를 위해 낮은 해상도를 사용합니다; 저장은 원래 해상도로 처리합니다. 여전히 효과가 너무 강하면, 부드러움(Smooth)을 낮추세요.

Q6: 홈 앨범으로 복사/업로드가 느린가요?

속도는 네트워크 대역폭과 파일 크기에 따라 달라집니다. 안정적인 Wi‑Fi 연결을 사용하세요.

Q7: 왜 SVG는 볼 수 있지만 편집할 수 없는가?

SVG는 벡터입니다. 이 앱은 벡터를 편집하고 SVG로 저장할 수 없고, 래스터화된 비트맵만 볼 수 있으므로 편집은 숨겨져 있습니다. §5.6을 참조하세요.

Q8: GIF / HEIC에 편집 버튼이 없는 이유는 무엇인가요?

이 형식들은 볼 수는 있지만, 편집된 저장본은 원래 형식(GIF 애니메이션, HEIC 인코딩)을 유지할 수 없습니다. 손상을 방지하기 위해, 편집은 .jpg, .jpeg, .png, .webp에만 해당됩니다.

Q9: 로컬 갤러리에서 SVG 파일이 누락되었나요?

Android MediaStore가 이를 인덱싱했는지 확인하세요 (Download초가 일반적인 경우입니다). 시스템이 SVG를 미디어로 등록하지 않았다면, 이 앱은 이를 목록에 표시할 수 없습니다.

Q10: 영상이 목록에 있지만 재생되지 않나요?

  • 확장이 §5.7에 있는지 확인하십시오
  • 휴대폰에서: 앱이 내장 엔진(Media3 또는 호환성 엔진)을 시도합니다. 실패하면 다른 앱으로 엽니다. 동일한 파일을 다른 플레이어에서 테스트할 수도 있습니다.
  • 네트워크 비디오: 네트워크를 확인하세요; 필요하면 설정에서 캐시를 지우고 다시 시도하세요

휴지통 옵션 (설정 → 로컬 갤러리 → 휴지통 옵션): 기본 삭제는 휴지통으로 이동 또는 영구 삭제; 휴지통 비우기 전에 확인; 만료 알림 (시스템이 약 하루 후 영구 삭제할 항목에 대한 일일 알림; Android 13+는 알림 권한 필요).

  • 기본값 = 휴지통으로 이동: 로컬 갤러리/뷰어에서 삭제하면 휴지통으로 이동(복원 가능).
  • 기본값 = 영구 삭제: 확인 후, 로컬 갤러리/뷰어에서 삭제하면 실제로 삭제되며, 그 삭제로 인해 휴지통에 들어가지 않아야 합니다. 휴지통에는 여전히 다른 이유로 항목이 표시될 수 있습니다:
  • 완전히 성공적으로 업로드한 후, 로컬 사본을 휴지통으로 이동하도록 선택했습니다(기본 삭제 설정과 무관하게)
  • 사진 편집은 덮어쓰기 전에 휴지통에 편집 전 백업을 보관합니다
  • 다른 앱 / 시스템 갤러리가 항목을 공유 MediaStore 휴지통으로 이동했습니다
  • 휴지통이 꺼져 있으면, 로컬 삭제는 항상 영구적입니다; 업로드가 성공해도 복사본을 휴지통으로 옮길지 묻지 않습니다.

12.5 Pro 자주 묻는 질문

Q: Basic가 편집, 삭제 및 업로드를 할 수 있나요?

네. Basic는 단순 보기용 앱이 아니라 완전한 사진 관리 프로그램입니다.

Q: 로컬 또는 홈 비디오에 Pro가 필요합니까?

아니요. 로컬 및 홈 비디오 재생은 Basic입니다. Pro은 자동 앨범 백업과 포토 캐스트를 잠금 해제합니다.

질문: 사진을 TV로 캐스팅하려면 Pro가 필요합니까?

네. Basic는 휴대폰에서 슬라이드쇼를 재생할 수 있습니다; TV 캐스트는 Pro가 필요합니다. 비디오 Cast는 Basic로 남아 있습니다.

Q: 비디오 캐스트에서 '비트레이트가 너무 높음'이라고 나오는 이유는 무엇인가요?

트랜스코드가 필요하지만 로컬 파일이나 트랜스코드 캐시가 아직 없는 경우에만. 일반적인 휴대폰 H.264는 직접 전송되며 비트레이트에 의해 차단되지 않습니다. HEVC 및 기타 TV 호환되지 않는 코덱은 먼저 준비됩니다. §5.7을 참조하십시오.

질문: 업로드는 백업과 어떻게 다른가요?

업로드는 파일과 홈 앨범 폴더(Basic 및 Pro)를 선택하는 것입니다. 휴지통이 켜져 있는 경우, 완전히 성공한 업로드는 공간을 절약하기 위해 로컬 사본을 휴지통으로 이동할 수 있습니다. 백업은 로컬 갤러리를 앱 관리 개인 백업 영역에 단방향으로 기록하고 기본적으로 로컬 사본을 유지합니다; 필요할 때 앱에서 복원할 수 있습니다.

Q: 앨범 백업은 Basic과 Pro에서 어떻게 다릅니까?

Basic은 수동 백업, 폴더 제외, 그리고 구형 전화 복원 / 연결을 지원합니다. Pro은 추가로 Wi‑Fi에서 자동 백그라운드 백업을 활성화할 수 있습니다.

Q: 백업은 양방향인가요?

아니요. 백업은 폰 → NAS입니다. NAS에서 백업 파일을 편집해도 폰에 다시 기록되지 않습니다. 복원은 앱에서 의도적으로 수행하는 동작입니다.

Q: Office Lens 파일은 Documents에 있습니다. Basic이 그것들을 볼 수 있나요?

예. Basic와 Pro은 설정 → 로컬 갤러리에서 Documents와 같은 병렬 폴더를 선택하고 승인할 수 있습니다.

Q: 복원할 때, Documents 및 다른 병렬 폴더들은 어디로 가나요?

그 폴더에 대해 SAF 없이: Pictures/ 아래의 매핑된 경로 (Documents/…로 돌아가지 않음). 해당 병렬 폴더가 허용된 경우: 원래의 상대 경로. 복원 확인 대화상자에는 매핑된 경로 수가 표시됩니다. §9.7을 참조하세요.

Q: Download 권한을 허용할 때 '이 폴더 사용'이 회색으로 표시되는 이유는 무엇인가요?

이것은 Android 11+ 시스템 제한입니다. 앱은 Download 루트에 대한 트리 권한을 얻을 수 없습니다. Documents를 선택하거나 Download 아래의 하위 폴더를 승인하세요. 앱은 “읽기 전용으로 Download 포함” 경로를 제공하지 않습니다(복사/복원 쓰기와 충돌하고 더 불편하기 때문입니다).
