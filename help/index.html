Getting started

  • Requires Android 11 or later.
  • On first launch, allow Photos and videos access.
  • Main screens use a bottom navigation bar (a side rail in landscape)—there is no sidebar drawer.
  • We do not host a cloud gallery. SMB passwords stay on your device.
  • If you used an older test build before the host/album refactor, clear app data or reinstall, then set up hosts and home albums again. Do not import old-format settings files.

Bottom navigation

TabWhat it does
LocalOn-device gallery (folders / timeline). With Pro + recycle bin enabled, open the bin from the local gallery title bar.
HomeOpens your last home album. Tap again to open/close the album picker (switch albums / manage).
BookmarksFolder bookmarks and video bookmarks (resume playback).
MoreAlbum backup (when enabled; may show a badge) and Settings. About / user guide live under Settings.

There is no separate “network storage” list. Browse NAS/PC files only via Home.

Local gallery

  • Folders or Timeline browse modes at the gallery root.
  • Long-press to multi-select; in folder mode, long-press a folder to select all media inside.
  • While selecting, long-press another item for an inclusive range select.
  • Toolbar actions: slideshow, copy, move, delete, share, upload to a home album.
  • Slideshow: multi-select photos → Slideshow, or start/pause from the photo viewer. About 5 seconds per photo, loops; tap to pause, swipe to change photo. Photos only (videos are skipped). Works with photo Cast when projecting.

Home albums & SMB hosts

  • SMB host: one NAS/PC plus credentials. Manage under More → Settings → Host connections. Add a host via the discovery dialog (or manual address), test, then save.
  • Home album: one card = one host + one share + one folder. Add multiple albums separately if you need more sources—setup creates one album at a time.
  • Typical setup: add a host in Settings (or from the home-album flow) → pick a share → pick a folder → done. Open from the Home tab.
  • Opening a subfolder loads from the server; going back uses a cached listing when available so the parent appears quickly.
  • Slideshow for photos works the same as in the local gallery (multi-select or from the viewer).
  • Video streaming (Pro): toggle under Settings → Home albums.

Haven’t shared a folder on your PC/NAS yet? See Set up home storage (Windows 11 walkthrough with screenshots; Synology / QNAP summaries).

Album backup & restore

One-way backup from the phone to a private folder on home storage: .HomeGallery/backup/{device}/. Not two-way sync. Open via More → Album backup (or Settings).

TopicWhat happens
BasicManual backup only, up to 1000 photos total
ProUnlimited + optional automatic backup on Wi‑Fi
Move to recycle binNAS copy kept; not listed as “Missing on device” — restore from the recycle bin
Permanent delete in this appNot “Missing on device”; next backup removes the matching NAS copy
Deleted outside the appListed as “Missing on device”; you can restore manually from the backup zone

Restore: More → Album backup → View backup / restore → filter Missing on device → restore selected or all missing.

Parallel folders (e.g. Documents) without SAF may restore under Pictures/…. See in-app prompts for path mapping.

Recycle bin vs permanent delete

  • Recycle bin (Pro): deleted items can be restored on the phone; home backup copies stay until you permanently delete. Open from the Local gallery title bar when Pro and enabled (hidden on Basic or when disabled).
  • Permanent delete: removes from the phone and schedules cleanup of the matching backup file on the next backup run.

Basic vs Pro

  • Basic (free): full local & home-album photo management, edit, upload, local video, slideshow, manual backup (1000 cap). No ads.
  • Pro (one-time): home-album video streaming, unlimited + auto album backup, recycle bin, parallel folders (SAF).

Support

  • In the app: More → Settings → About → User guide, or Settings → Support.
  • Report issues from Settings / About (email). Optional diagnostic ZIP — no passwords or photo contents.
  • Settings export may include SMB credentials in an encoded form (not immediately readable, not strong encryption)—keep export files private.

開始使用

  • 需 Android 11 或以上。
  • 首次啟動請允許相片和影片存取。
  • 主畫面使用底部導航（橫向為側邊導覽列），沒有側邊欄抽屜。
  • 本 App 不提供雲端相簿代管；網路儲存帳密僅保存在您的裝置上。
  • 若曾使用重構前的舊測試版，請先清除 App 資料或重裝，再重新設定主機與家中相簿；勿匯入舊格式設定檔。

底部導航

分頁說明
本機本機相簿（資料夾／時間軸）。Pro 且啟用回收桶時，可從本機標題列進入回收桶。
家中進入上次使用的家中相簿；再點一次開啟／關閉相簿選擇器（切換或管理相簿）。
書籤資料夾書籤與影片書籤（可續播）。
更多相簿備份（啟用時顯示，可能有徽章）與設定。關於／使用說明在設定內。

沒有「網路儲存」連線列表；家中檔案一律由家中進入。

本機相簿

  • 根目錄可切換資料夾或時間軸瀏覽。
  • 長按進入多選；資料夾模式下長按資料夾可選取該夾全部媒體。
  • 多選中再長按另一項可區間多選（含兩端）。
  • 可投影片、複製、移動、刪除、分享、上傳至家中相簿。
  • 投影片：多選相片後點「投影片」，或在瀏覽頁開始／暫停。約每張 5 秒、循環播放；輕觸暫停、左右滑切換。僅相片（略過影片）。相片 Cast 投影時亦可同步換頁。

家中相簿與主機連線

  • SMB 主機：一台 NAS／PC 加上帳密。在更多 → 設定 → 主機連線管理登記。透過探索對話框（或手動輸入）新增、測試連線後儲存。
  • 家中相簿：一張卡片＝一台主機＋一個共用＋一個資料夾。需要多個來源就分別新增——一次流程只建一筆。
  • 建議流程：先新增主機 → 選共用 → 選資料夾 → 完成。再到底部導航「家中」瀏覽。
  • 進入子目錄需向伺服器載入；返回上層會盡量使用已快取列表，讓上層較快出現。
  • 投影片與本機相簿相同（多選或瀏覽頁啟動）。
  • 網路影片串流（Pro）：開關在設定 → 家中相簿區塊。

還沒在電腦／NAS 開過共用？請先看 家中儲存建置指南（Windows 11 含截圖；Synology／QNAP 為步驟摘要）。

相簿備份與還原

將本機相簿單向備份到家中儲存私有區：.HomeGallery/backup/{裝置}/。不是雙向同步。入口：更多 → 相簿備份（或設定）。

情境說明
Basic僅手動備份，累計最多 1000 張
Pro無張數上限；Wi‑Fi 下可自動備份
移至回收桶家中備份保留；不算「本機缺失」——請從回收桶還原本機
本 App 永久刪除不算「本機缺失」；下次備份會清除對應的家中備份檔
外部／未知消失列為「本機缺失」，可手動從備份區還原

還原：更多 → 相簿備份 → 檢視備份／還原 → 篩選「本機缺失」→ 還原已選或全部缺失。

平行目錄（如 Documents）若尚未 SAF 授權，還原可能寫入 Pictures/…；請依對話框的路徑映射提示確認。

回收桶與永久刪除

  • 回收桶（Pro）：可還原本機項目；在回收桶期間家中備份仍保留。於本機相簿標題列進入（僅 Pro 且已啟用；Basic 或關閉時隱藏）。
  • 永久刪除：自手機刪除，並在下次備份時清除對應的備份檔。

Basic 與 Pro

  • Basic（免費）：本機與家中相簿相片管理、編輯、上傳、本機影片、投影片、手動備份（1000 張上限）。無廣告。
  • Pro（一次性）：家中相簿影片串流、備份無上限與自動備份、回收桶、平行目錄（SAF）。

說明與支援
