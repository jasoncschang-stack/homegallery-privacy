Home GalleryのためにSynology NAS共有を有効にする

Home Gallery

繁體中文 English 日本語 한국어 トラブルシューティング

ブラウザでサインインでき、DSMがすでにインストールされている場合、約15～25分です。その後、Home GalleryはNASをホームストレージとして使用できます。

DSM 7.x 向けに作成（一般的な 7.2–7.4 のメニュー）。ラベルが異なる場合は、コントロールパネルで SMB または 共有フォルダー を検索してください。
電話はフォルダを SMB 以上で読み取ります。

はじめる前に

  • DSM はブラウザで開きます（例：http://NAS-IP:5000 または QuickConnect）
  • あなたは管理者（または同等の）アカウントを持っています
  • 電話とNASは同じホームWi‑Fi / LANにあります
  • 写真の保存場所を決める: 新しい共有フォルダ（例: photos）か、既存の共有フォルダのサブフォルダ

ステップ 1: SMB を有効にする

  1. DSMにサインインしてください
  2. コントロールパネル を開きます
  3. ファイルサービスを開く
  4. SMB セクション/タブを開く
  5. SMBサービスを有効にする にチェックを入れます（場合によっては SMB/CIFS）
  6. 適用 をクリック

(スクリーンショット: ファイルサービス → SMBを有効にする)

推奨される高度なオプション

SMB 高度な設定 の下で:

  • 最小/最大SMBプロトコルはデフォルトのままにする（SMB2以上）
  • 互換性のためにSMB1を有効にしないでください（セキュリティリスク; Home Galleryには必要ありません）
  • 基本的な接続が動作するまで、暗号化のみの実験はスキップする

ステップ2: 共有フォルダを作成または確認する

  1. コントロールパネル → 共有フォルダー
  2. 適切な共有が既に存在する場合は、その名前をメモしてステップ3に進んでください
  3. それ以外の場合は 作成 → 共有フォルダーを作成 を選択し、次を設定します:
  4. 名前: 例 FamilyPhotos（アプリでは共有フォルダとして表示されます）
  5. 任意の説明; 最初の設定では他のオプションはデフォルトのままにしてください
  6. 共有がリストに表示されていることを確認してください

（スクリーンショット：共有フォルダーのリスト）

権限が正しく、写真が存在する（あるいはこれから存在する）場合は、photoのような組み込み共有も問題ありません。

ステップ3：ユーザー権限

  1. 共有を選択 → 編集
  2. 権限 を開く
  3. 電話で使用するアカウントについては、読み取り/書き込みを優先してください
  4. アップロード、移動/コピー、編集、アルバムのバックアップには書き込み権限が必要です；読み取り専用では後でしばしば失敗します
  5. 電話が書き込みを一切行わない場合のみ、読み取り専用を使用してください
  6. 適用する

（スクリーンショット：共有権限）

推奨：電話のみのユーザー

  1. コントロールパネル → ユーザーとグループ
  2. ユーザーを作成 例: homegallery
  3. パスワードを設定する
  4. 管理者は不要—写真共有は読み取り/書き込みのみ
  5. 管理者パスワードを電話に保存する代わりに、このアカウントをアプリで使用してください

ゲスト/匿名アクセスに頼らないでください。

ステップ4：写真を共有に入れる（任意だが推奨）

  1. ファイルステーション を開きます
  2. 共有フォルダー（またはサブフォルダー）を開きます
  3. 写真やビデオをアップロードまたは移動する

アプリでホームアルバムを追加するときは、この共有を選び、次に実際に写真が入っているフォルダを選んでください。

ステップ5：接続の詳細を記録する

| アイテム | 入手場所 |

|------|------------------|

| NAS 名前 | DSM デスクトップ / インフォセンター |

| IPアドレス | コントロールパネル → 情報センター、またはルーターのDHCPリスト |

| ユーザー名 / パスワード | ステップ3のアカウント |

もし検出に失敗した場合は、Home GalleryにIPを手動で入力してください。

ステップ6：Home Galleryで接続

  1. 電話は同じ家にWi‑Fi
  2. ホーム → ホームストレージに接続（または その他 → 設定 → ホスト接続 → SMBホストを追加）
  3. スキャンからNASを選択するか、IPを入力してください
  4. 資格情報 → 接続をテスト → 保存
  5. 共有フォルダーを選択 → アルバムフォルダー → 完了

アプリの詳細：user manual §4（繁体字中国語のソース）。

完了チェックリスト

  • SMB サービスが有効化され、適用されました
  • 共有が存在する；アカウントには読み取りまたは読み取り/書き込みの権限がある
  • 電話とNASが同じLAN上にある
  • アプリの接続テストが機能する；フォルダが開く
  • （バックアップ）アカウントは読み書き可能です

失敗した場合：Troubleshooting。

短いFAQ

QuickConnectが必要ですか？ ホームLANには不要SMBです。LANのIPまたはホスト名を使用してください。QuickConnectは主にリモートDSM管理用です。

ファイアウォール？ DSM のファイアウォールがオンの場合、SMB（TCP 445）へのLANアクセスを許可します。

5Gで自宅外にいるとき？ 自宅Wi‑FiではアプリはまだSMBを使用します。自宅外では、リモートアクセスをWebDAV（DDNS / 公開IP + HTTPSポート）に設定してください—webdav.mdを参照。Windows PCの場合は、Tailscaleを使用してください。
