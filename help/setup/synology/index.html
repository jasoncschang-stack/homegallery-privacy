使用說明/家中儲存建置/Synology

Synology NAS 開通共用

DSM 7.x · 約 15～25 分鐘 · 截圖待補

繁體中文English排查

步驟摘要

  1. 控制台 → 檔案服務 → SMB：啟用 SMB 服務 → 套用（勿開 SMB1）
  2. 控制台 → 共用資料夾：新增或選取要給手機用的共用（例如 FamilyPhotos）
  3. 編輯 → 權限：建議手機帳號讀寫（上傳／移動／編輯／備份需要）；勿用 Guest
  4. 用 File Station 放入相片（可選）
  5. 記下 NAS 名稱／IP／帳密
  6. 手機同一 Wi‑Fi → Home Gallery → 連線家中儲存 → 選共用 → 完成

完整文字稿見 App 倉庫 docs/setup-home-storage/synology.md。公開頁截圖補齊後會與 Windows 篇同樣嵌入圖示。
