Synology NAS sharing

DSM 7.x · about 15–25 minutes · Screenshots pending

Steps (summary)

  1. Control Panel → File Services → SMB: Enable SMB service → Apply (do not enable SMB1)
  2. Control Panel → Shared Folder: create or pick a share for the phone
  3. Edit → Permissions: prefer Read/Write for the phone account (needed for upload/move/edit/backup); not Guest
  4. Optional: put photos in File Station
  5. Note NAS name / IP / credentials
  6. Same Wi‑Fi → Home Gallery → Connect home storage → pick share → Finish
