繁體中文 — 請選一條路

想用家相簿連線家中照片，但還沒在電腦／NAS 開好「共用資料夾」？請先完成建置，再到 App 新增主機。

Windows 11 電腦 建議入門 在 PC 開通共用資料夾（含截圖） Synology NAS 啟用 SMB 與共用權限（截圖待補） QNAP NAS 啟用 Microsoft 網路與權限（截圖待補） 連不上？排查 找不到主機、帳密失敗、只讀、外網 外出／WebDAV（NAS） HTTPS WebDAV：DDNS／公網 IP + 埠 外出／Tailscale（Windows） PC＋手機＋App 貼上 100.x

成功標準：App 能連上主機、開啟相片資料夾；若要用備份，共用需可寫入。外出：NAS 見 WebDAV；Windows 見 Tailscale。

English — Choose a path

Use Home Gallery with photos on home storage, but have not shared a folder yet? Set up sharing first, then add the host in the app.

Windows 11 PC Start here Share a folder on your PC (with screenshots) Synology NAS Enable SMB and permissions (screenshots pending) QNAP NAS Enable Microsoft Networking (screenshots pending) Connection troubleshooting Not found, login failed, read-only, mobile data Away / WebDAV (NAS) HTTPS WebDAV: DDNS / public IP + port Away / Tailscale (Windows) PC + phone + paste 100.x in the app

Success: the app connects and opens your photo folder. For album backup, the share must be writable. Away: NAS → WebDAV; Windows → Tailscale.
