繁體中文

什麼時候需要？

  • 人在家、連家中 Wi‑Fi → 不需要 Tailscale
  • 外出、NAS 可開 HTTPS WebDAV → 優先用 WebDAV
  • 外出、Windows PC（或無法開 WebDAV）→ 需要 Tailscale
  • 已用 OpenVPN 等連進家中區網 → 不必再開 Tailscale

請在 App 填 100.x IP，不要只靠 MagicDNS 名稱。

1. PC／NAS（家中）

  1. 開啟 tailscale.com/download，安裝並登入
  2. 確認狀態為 Connected
  3. 複製這台電腦／NAS 的 Tailscale IPv4（100.x）

2. 手機

  1. Google Play 安裝 Tailscale
  2. 用與 PC 相同帳號登入，允許 VPN
  3. 確認 Connected，列表中看得到家中那台裝置

3. Home Gallery（首次外出設定）

  1. 先在家中 Wi‑Fi把主機與家中相簿設好
  2. 外出開啟該相簿 → 若提示需要 Tailscale，點開啟 Tailscale
  3. 在 Tailscale 複製 PC 的 100.x
  4. 返回 App（畫面會停著讓你貼上，不會立刻狂重連）
  5. 點貼上 → 儲存 Tailscale IP 並重試

也可到設定 → 主機連線管理 → 編輯，在 Tailscale 欄填入 100.x（區網 IPv4 欄請維持 192.168.x）。

日常與耗電

  • 要看相簿再開 Tailscale；看完可離開 App（約數十秒後會請 Tailscale 斷線）
  • 回到家中 Wi‑Fi 時，App 也可能請 Tailscale 斷線

常見問題

貼上後仍連不上？ 確認 PC／手機同一 Tailscale 帳號且皆 Connected；複製的是家中那台的 100.x；在家 Wi‑Fi 用同一組 SMB 帳密仍可連；PC 未睡眠。

OpenVPN？ 已進區網則維持區網 IPv4 即可，不必再開 Tailscale。

English

When do you need Tailscale?

  • At home on Wi‑Fi → not needed
  • Away, NAS with HTTPS WebDAV → prefer WebDAV
  • Away, Windows PC (or no WebDAV) → use Tailscale
  • Already on a home-LAN VPN (e.g. OpenVPN) → Tailscale not required

Save the 100.x IP in the app — do not rely on MagicDNS alone.

1. PC / NAS

  1. Install from tailscale.com/download and sign in
  2. Confirm Connected
  3. Copy this machine’s Tailscale IPv4 (100.x)

2. Phone

  1. Install Tailscale from Play Store
  2. Sign in with the same account; allow VPN
  3. Confirm Connected and that the home PC/NAS appears

3. Home Gallery (first away setup)

  1. On home Wi‑Fi, finish the SMB host and home album first
  2. Away: open the album → if prompted, tap Open Tailscale
  3. Copy the PC’s 100.x in Tailscale
  4. Return to the app (it stays on the paste screen — no auto thrash)
  5. Paste → Save Tailscale IP and retry

Or edit the host under Settings → Host connections and fill the Tailscale field (keep LAN IPv4 separate).

Daily use

  • Turn Tailscale on when you need the album; leaving the app asks Tailscale to disconnect after a short delay
  • Back on matching home Wi‑Fi, the app may also disconnect Tailscale

約 15～30 分（PC とスマホそれぞれ 1 回ずつ含む Tailscale）。

1. いつ Tailscale が必要ですか？

| シチュエーション | 提案 |

|------|------|

| 人が家にいるとき、携帯は家に接続 Wi‑Fi | 不要 Tailscale；ローカルネットワーク IPv4／ホスト名で十分 |

| 外出、NAS 開けても良い HTTPS WebDAV | 優先的に使う WebDAV |

| 外出、Windows PC（またはWebDAVを開けないSMBのホスト） | 必要 Tailscale（またはすでに持っている家庭内ネットワークVPN、§7参照） |

| すでに OpenVPN／WireGuard などで自宅のネットワークに接続済み | もう Tailscale を開く必要はなし；アプリがネットワーク内のアドレスを試す |

Tailscale は携帯電話と自宅の PC／NAS の間で暗号化接続を確立し、各デバイスに 100.x.x.x アドレス（CGNAT）を割り当てます。ホームギャラリー 外出時は優先的にこのアドレスで SMB に接続します。

IPを使用してください。MagicDNS名だけに頼らないでください。 アプリの「Tailscale」欄には100.xを入力してください。名前解決は携帯電話では失敗しやすいです。

2. 開始前に確認してください

  • 家中の PC／NAS はすでにセットアップ済み SMB 共有されており、かつ 家の中の Wi‑Fi で ホームギャラリー 接続でき、アルバムを閲覧できる
  • ホストはアプリの ホスト接続管理 にすでにアカウント情報があります；ローカルネットワーク IPv4（例：192.168.x.x）は入力済みであることを推奨
  • PC／NAS と携帯の両方でインターネットに接続できる（外出時は携帯でモバイルデータを使用すればよい）
  • Google／Microsoft／GitHub などのアカウントでログイン可能 Tailscale（無料の個人プランで十分な場合が多い）

3. 家の PC（または NAS）に Tailscale をインストールしてログインする

以下は Windows を例とします；Linux NAS／その他のシステムは Tailscale 下載頁 で対応するインストール方法を選択してください。原則は同じです：インストール → 同じアカウントでログイン → 接続済みであることを確認 → 100.x をメモ。

3.1 インストール

  1. コンピュータでブラウザを開き、https://tailscale.com/download にアクセスします
  2. Windows 版をダウンロードしてインストールする
  3. インストールが完了したら Tailscale を開き、あなたのアカウントでログインしてください（後でスマートフォンでも同じ Tailscale／尾網アカウントにログインする必要があります）

3.2 接続が確認されました

  1. システムトレイ（右下隅）で Tailscale アイコンを見つける
  2. 状態は Connected／接続済みであるべきです
  3. Tailscale ウィンドウまたはウェブ管理（https://login.tailscale.com/admin/machines）を開き、このコンピューターがデバイス一覧に表示されていることを確認します

3.3 このコンピューターの Tailscale IPv4 を複製する

  1. Tailscale ウィンドウまたはデバイス一覧で、ローカルの IPv4（100.64.x.x～100.127.x.x の形式）を見つけます
  2. コピーその住所（後でスマホのアプリに貼り付ける）
  3. このアドレスをメモ帳に記録することをお勧めします；機種変更や Tailscale 再インストール後、アドレスが変更される可能性があるため、アプリを再更新する必要があります

PC ファイアウォール： LAN SMB に既に接続できる場合、通常 Tailscale のために別規則を作成する必要はありません。もし 100.x のみが接続できない場合は、Windows の「ファイルとプリンターの共有」がまだ許可されているか、そしてコンピュータがスリープ状態でないかを確認してください。

3.4 NAS 補足

  • 部分 NAS は Tailscale パッケージ／Docker をインストール可能；インストールして同じアカウントにログインした後、同じようにそのデバイスの 100.x をコピーします。
  • もし NAS を インストールしない Tailscale、家の常に電源が入っている PC にだけインストールしても構いません——前提として、写真が実際にその PC の共有上にあるか、または別に接続可能なパスがあることが必要です。

4. 携帯電話にインストールしてログイン Tailscale

  1. Google Play で Tailscale をインストールする（パッケージ名はおおよそ com.tailscale.ipn）
  2. Tailscale を開き、PC と 同じ アカウントでログインする
  3. 提示に従って VPN 接続 を作成する（Android システムが確認します）
  4. 状態が 接続済み であることを確認
  5. Tailscale のデバイスリストで、家の PC／NAS を見ることができるはずです

この時すぐに Tailscale を閉じないでください；次のステップで ホームギャラリー に 100.x を貼り付けます。

5. ホームギャラリー で設定を完了する（推奨手順）

5.1 まず家で本体とアルバムをセットアップする

  1. 携帯電話を家に接続する Wi‑Fi
  2. 設定 → ホスト接続管理：ホスト（アカウント情報、LAN IPv4）を追加または確認
  3. 家庭アルバムを作成し、閲覧できることを確認する

外出時は再処理 Tailscale 欄だけで大丈夫です。

5.2 外出時：アプリの指示に従って完了（初回が最もスムーズ）

  1. モバイルデータ（または自宅以外 Wi‑Fi）に切り替える
  2. ホームギャラリー を開く → 家の中 → そのアルバムを選択
  3. もしリモートアクセスが Tailscale で、まだ Tailscale の IP が保存されていない場合、画面には Tailscale が必要であることが説明され、次のものが提供されます：
  4. インストール／開く Tailscale
  5. Tailscale IPv4 入力欄、貼り付け、Tailscale IP を保存して再試行
  6. Tailscaleを開く（未インストールの場合は Play ストアに移動）
  7. Tailscale で Connected になっていることを確認し、家庭用 PC の行で IPv4（100.x）をコピー
  8. 戻る ホームギャラリー（画面はサポートページにとどまり、すぐに自動で再接続はされません）
  9. 貼り付け をクリックする（または手動で 100.x を入力）
  10. 保存 Tailscale IP をクリックして再試行

成功後はその家のアルバムを閲覧するために外出できます。住所はこの端末の設定に保存され、以後は通常再度入力する必要はありません。

5.3 「ホスト接続」で手動入力することもできます

  1. 設定 → ホスト接続管理 → 編集 そのホスト
  2. Tailscale 欄に 100.x を入力してください（ローカルネットワーク IPv4 欄は自宅の 192.168.x.x を維持し、両方を分けてください）
  3. 接続テスト → 保存

6. 日常使用と消費電力

| タイミング | 推奨 |

|------|------|

| アルバムを見に外出する必要があります | Tailscale を開く → 接続する → もう一度開く／ホームギャラリー に戻る |

| アプリを見終わったら終了 | アプリはバックグラウンドに入ってから数十秒後に、Tailscale の接続を切断します（ずっと電力を消費するのを防ぐため）。次回外出時に再度開けばOKです |

| 家に戻る Wi‑Fi | アプリが既に保存されたホストと一致する家庭内ネットワークを検出した場合、Tailscale に切断を依頼します |

| 在宅時 | Tailscaleを開く必要なし；ローカルネットワークのアドレスの方が速く、節電できる |

ホームギャラリー アプリ内でバーコードをスキャンして交換することはできません；Tailscale アカウントと接続は Tailscale アプリ／公式サイトで管理されています。

7. すでに OpenVPN／他の家庭内ネットワーク VPN がある場合

もしも元々 OpenVPN や WireGuard などで自宅のローカルネットワークに接続している場合（スマホで 192.168.x.x に ping が通る）：

  • ～する必要はない ホームギャラリー を再開 Tailscale
  • ホスト上のローカルネットワーク IPv4（またはローカルネットワーク IPv6）を正しく維持してください
  • アプリがこの種類の VPN を検出したときは、ローカルネットワークのアドレスを試みますが、強制的に開くことはありません Tailscale

Tailscale 「進区ネットワークの従来型VPN」とは異なり：Tailscale デフォルトで100.xが設定されており、通常192.168.xを自動的にローカルネットワークとして扱うことはありません；そのため、外出先でTailscaleを使用する場合は、必ずアプリにTailscale IPv4を入力してください。

8. よくある質問

Q1：Tailscale を開いた後、アプリに戻ると、ずっと接続 1/1、1/2 と表示され、その後失敗しますか？

「外出 Tailscale 協助」修正を含むバージョンに更新してください：アプリに戻った後は、IP を貼り付けられる画面にとどまる必要があります。もしまだ頻繁に再接続する場合は、まずアプリを完全に閉じてから再起動し、100.x を「区網 IPv4」欄に誤って入力していないか確認してください。

Q2：貼り付けた後もつながらない？

  • PCと携帯 Tailscale は両方とも 接続済み で、同じアカウントですか？
  • 複製されたのは家のあの機械の 100.x（携帯自身のものではない）ですか？
  • 家の中でWi‑Fi同じSMBのアカウント情報を使ってもまだ接続できますか？
  • PCはスリープ状態ですか？再試行する前に、スリープ解除してください

Q3：MagicDNS の名前だけを入力できますか？

唯一の接続方法としては推奨されません。Appの Tailscale 欄に 100.x IP を保存してください。

Q4：パソコンを交換／再インストール Tailscale 後？

100.x 変更される可能性があります。新しいデバイスに新しいIPv4をコピーし、アプリのサポート画面またはホスト接続で更新してから再度接続してください。

Q5：安全ですか？

トラフィックは Tailscale 暗号化トンネルを通ります；SMB アカウント情報は引き続きあなたの携帯電話上だけに存在します ホームギャラリー。Tailscale アカウントでのログイン情報を信頼できない人と共有しないでください。また、定期的に 管理後台 で不要なデバイスを削除してください。

한국어 — 외출용 Tailscale 집으로 돌아가는 앨범 연결 (사용 설명서)

한국어 전용 화면이 없으면 영어 스크린샷을 사용합니다.

적용: 홈 갤러리 이미 집에서 Wi‑Fi로 SMB 서버에 연결할 수 있지만, 외출 시(모바일 데이터/외부 네트워크 Wi‑Fi) Tailscale 연결을 사용해야 함 —— 주로 Windows PC에서 흔하며, NAS 외부에 WebDAV 열 수 없거나/열고 싶지 않을 때.

로컬 네트워크 구축의 차이점: Windows 11／NAS 建置 집에서 공유하는 방법을 가르쳐줌; 이 페이지에서는 외출 시 Tailscale를 '보안 터널'로 사용하는 방법을 가르쳐줌.
NAS 그리고 이미 열었습니까 HTTPS WebDAV？ WebDAV 手冊를 사용하는 것이 좋으며, 일반적으로 Tailscale를 설치할 필요가 없습니다.
앱 총 매뉴얼: user-manual.md §4.4.

약 15~30분 정도 소요됩니다 (PC와 휴대폰 각각 한 번 설치 포함 Tailscale).

1. Tailscale가 언제 필요합니까?

| 상황 | 제안 |

|------|------|

| 사람이 집에 있을 때, 휴대폰이 집과 연결 Wi‑Fi | 필요하지 않음 Tailscale；로컬 네트워크 IPv4／호스트 이름으로 가능 |

| 외출, NAS 열 수 있음 HTTPS WebDAV | 우선 사용 WebDAV |

| 외출, Windows PC(또는 WebDAV를 열 수 없는 다른 SMB 호스트) | 필요 Tailscale(또는 이미 집에 있는 LAN VPN, §7 참조) |

| 이미 OpenVPN／WireGuard 등으로 집 내부 네트워크에 연결됨 | 더 이상 Tailscale을 열 필요 없음; 앱이 내부 네트워크 주소를 시도할 것

Tailscale 휴대폰과 집의 PC/NAS 사이에 암호화 연결을 구축하고, 각 장치에 100.x.x.x 주소(CGNAT)를 부여합니다. 홈 갤러리 외출 시 우선 이 주소를 사용하여 SMB에 연결합니다.

IP를 사용하고, MagicDNS 이름만 의존하지 마세요. 앱의 'Tailscale' 칸에는 100.x을 입력하세요; 이름 해석은 휴대폰에서 실패할 가능성이 더 높습니다.

2. 시작하기 전에 확인하세요

  • 집 PC／NAS 이미 설정 완료 SMB 공유, 그리고 집 Wi‑Fi에서 홈 갤러리 접속 가능, 앨범 열람 가능
  • 호스트는 App 호스트 연결 관리에 이미 계정과 비밀번호가 있음; 로컬 네트워크 IPv4(예: 192.168.x.x) 권장 이미 입력됨
  • PC／NAS와 휴대폰 모두 인터넷에 연결 가능（외출 시 휴대폰은 모바일 데이터를 사용하면 됨）
  • Google/Microsoft/GitHub 등의 계정으로 로그인 가능 Tailscale（무료 개인 플랜이면 보통 충분）

3. 집에서 PC(또는 NAS)에 Tailscale를 설치하고 로그인하기

아래는 Windows를 예로 든 것입니다; Linux NAS/기타 시스템은 Tailscale 下載頁로 가서 해당 설치 방법을 선택하세요, 원칙은 같습니다: 설치 → 동일 계정으로 로그인 → 연결 여부 확인 → 100.x 기록.

3.1 설치

  1. 컴퓨터에서 브라우저를 열고 https://tailscale.com/download로 이동합니다.
  2. Windows 버전을 다운로드하고 설치합니다
  3. 설치가 완료된 후 Tailscale를 열고, 당신의 계정으로 로그인하세요 (이후 휴대폰에서도 같은 Tailscale/웨이웹 계정으로 로그인해야 합니다)

3.2 연결 확인

  1. 시스템 트레이(오른쪽 아래)에서 Tailscale 아이콘을 찾습니다
  2. 상태는 Connected/연결됨이어야 합니다
  3. Tailscale 창이나 웹 페이지 관리(https://login.tailscale.com/admin/machines)를 열고, 이 컴퓨터가 장치 목록에 나타나는지 확인합니다.

3.3 이 컴퓨터의 Tailscale IPv4 복제

  1. Tailscale 창이나 장치 목록에서 로컬 IPv4(100.64.x.x~100.127.x.x 형태)을 찾습니다
  2. 복사 해당 주소(나중에 휴대폰 앱에 붙여넣기)
  3. 이 주소를 메모장에 적어두는 것을 권장합니다; 기기 교체나 Tailscale 재설치 후 주소가 변경될 수 있으므로 App을 다시 업데이트해야 합니다

PC 방화벽: 만약 LAN SMB 연결이 이미 가능하다면, 일반적으로 Tailscale 용으로 별도의 규칙을 만들 필요가 없습니다. 만약 오직 100.x 만 연결이 안 된다면, Windows의 '파일 및 프린터 공유'가 여전히 허용되어 있는지, 그리고 컴퓨터가 절전 모드가 아닌지 확인하세요.

3.4 NAS 보충

  • 일부 NAS는 Tailscale 패키지/Docker를 설치할 수 있습니다; 설치 후 같은 계정으로 로그인하면, 동일하게 해당 장치의 100.x를 복사할 수 있습니다.
  • 만약 NAS 설치하지 않고 Tailscale를 오직 항상 켜져 있는 집의 PC 한 대에만 설치해도 된다——전제는 사진이 실제로 그 PC의 공유에 있거나, 또는 다른 연결 가능한 경로가 있는 경우이다.

4. 휴대폰에 설치하고 로그인 Tailscale

  1. Google Play에서 Tailscale 설치（패키지명은 대략 com.tailscale.ipn）
  2. Tailscale를 열고, PC와 같은 계정으로 로그인하세요
  3. 안내에 따라 VPN 연결을 허용합니다(안드로이드 시스템에서 묻습니다)
  4. 상태가 Connected인지 확인
  5. Tailscale 장치 목록에서 집에 있는 그 PC/NAS를 볼 수 있어야 합니다.

이때 먼저 서둘러 Tailscale를 닫지 마세요; 다음 단계에서 Home Gallery에 100.x를 붙여 넣으세요.

5. Home Gallery에서 설정 완료하기（권장 절차）

5.1 먼저 집에서 메인 기기와 앨범을 설정하세요

  1. 휴대전화가 집에 연결됨 Wi‑Fi
  2. 설정 → 호스트 연결 관리: 호스트 추가 또는 확인 (계정/비밀번호, 로컬 네트워크 IPv4)
  3. 집안 사진첩을 만들고 볼 수 있는지 확인하기

외출할 때 다시 처리 Tailscale 칸만 하면 됩니다.

5.2 외출 시: 앱 안내에 따라 완료 (처음이 가장 순조로움)

  1. 모바일 데이터로 전환하기 (또는 집 밖 Wi‑Fi)
  2. 홈 갤러리 열기 → 집 → 해당 앨범 선택
  3. 원격 접근이 Tailscale이고 아직 Tailscale IP가 저장되지 않은 경우, 화면에서 Tailscale가 필요함을 설명하고 다음을 제공합니다:
  4. 설치/열기 Tailscale
  5. Tailscale IPv4 입력란, 붙여넣기, Tailscale IP 저장 후 다시 시도
  6. Tailscale 열기 클릭 (설치되어 있지 않으면 Play 스토어로 이동)
  7. Tailscale에서 Connected를 확인한 후, 집 PC 열에서 IPv4(100.x) 복사
  8. Home Gallery으로 돌아가기（화면은 도움말 페이지에 머물며, 즉시 자동으로 재연결되지 않습니다）
  9. 붙여넣기를 클릭합니다(또는 100.x을 수동으로 입력합니다)
  10. 저장 Tailscale IP 후 재시도를 클릭

성공한 후에는 해당 집의 사진첩을 외부에서 열람할 수 있습니다. 주소는 이 기기의 설정에 기록되며, 이후에는 보통 다시 입력할 필요가 없습니다.

5.3 "호스트 연결"에서 수동으로 입력할 수도 있습니다

  1. 설정 → 호스트 연결 관리 → 편집 해당 호스트
  2. Tailscale 칸에 100.x를 입력하세요 (로컬 네트워크 IPv4 칸은 집에 있는 192.168.x.x를 유지하고, 두 개를 분리하세요)
  3. 연결 테스트 → 저장

6. 일상 사용과 전력 소모

| 시기 | 추천 |

|------|------|

| 외출해서 사진첩 보기 | Tailscale 열기 → 연결 → 다시 열기／Home Gallery로 돌아가기 |

| 앱 보고 나서 나가기 | 앱이 백그라운드로 들어간 지 약 수십 초 후, Tailscale 연결 종료(계속 전력 소모 방지). 다음에 외출할 때 다시 열면 됩니다 |

| 집으로 돌아가기 Wi‑Fi | 앱이 이미 저장된 호스트와 일치하는 가정용 네트워크를 감지하면, Tailscale에게도 연결 종료를 요청합니다 |

| 집에 있을 때 | Tailscale를 켤 필요 없음; 로컬 네트워크 주소를 이용하면 더 빠르고 전력 소모가 적음 |

홈 갤러리 앱 내에서 바코드를 스캔하여 교환하지 않습니다; Tailscale 계정과 연결은 모두 Tailscale 앱/공식 웹사이트에서 관리합니다.

7. 이미 OpenVPN/다른 가정용 LAN VPN이 있을 때

만약 당신이 원래 OpenVPN, WireGuard 등을 이용해 집 안 네트워크에 접속하고 있다면(휴대폰으로 192.168.x.x에 ping 가능):

  • Home Gallery을/를 위해 Tailscale을/를 다시 열 필요 없음
  • 호스트에서 LAN IPv4(또는 LAN IPv6)이 올바른지 유지해 주세요
  • 앱이 이러한 VPN을 감지하면, 테스트용 네트워크 주소를 시도하며, Tailscale를 강제로 열도록 하지 않습니다.

Tailscale 기존의 '사내망 전용 VPN'과 달리: Tailscale 기본적으로 제공되는 것은 100.x이며, 일반적으로 자동으로 192.168.x를 사내망으로 간주하지 않습니다; 따라서 외부에서 Tailscale를 사용할 때에는, 반드시 앱에 Tailscale IPv4를 입력해야 합니다.

8. 자주 묻는 질문

Q1：Tailscale를 연 후 앱으로 돌아가면 계속 연결 1/1, 1/2가 표시되다가 실패하나요?

「외출 Tailscale 지원」이 수정된 버전으로 업데이트해 주세요: 앱을 다시 열면 IP를 붙여넣을 수 있는 화면에 머물러야 합니다. 계속해서 재접속이 반복된다면, 먼저 앱을 완전히 종료했다가 다시 열고, 100.x을 실수로 '로컬 네트워크 IPv4' 칸에 입력하지 않았는지 확인하세요.

Q2: 붙여도 여전히 연결이 안 되나요?

  • PC와 휴대폰 Tailscale 모두 Connected 상태이며, 같은 계정인가요?
  • 복사한 것이 집에 있는 그 100.x인가요 (휴대폰 자체 것이 아닌가요)?
  • 집에서 Wi‑Fi 같은 SMB 계정으로 여전히 연결할 수 있나요?
  • PC가 절전 모드에 있나요? 깨운 후 다시 시도하세요

Q3: MagicDNS 이름만 입력해도 되나요?

유일한 연결 방식으로 사용하지 않는 것이 좋습니다. 앱 Tailscale 칸에 100.x IP를 저장하십시오.

Q4: 컴퓨터를 바꾸거나 재설치 Tailscale 후?

100.x 변경될 수 있습니다. 새 장치에 새로운 IPv4을 복사하고, 앱 도움말 화면이나 호스트 연결에서 업데이트한 후 다시 연결하세요.

Q5：안전한가요?

트래픽은 Tailscale 암호화 터널을 통해 흐릅니다; SMB 계정과 비밀번호는 여전히 당신의 휴대폰에만 홈 갤러리 존재합니다. Tailscale 로그인 정보를 신뢰하지 않는 사람과 공유하지 마시고, 管理後台에서 사용하지 않는 기기를 정기적으로 제거하세요.

9. 단계 빠른 확인

```

家中 Wi‑Fi：設好 SMB 主機 + 家中相簿（區網可連）

↓

PC／NAS：安裝 Tailscale → 登入 → Connected → 複製 100.x

↓

手機：安裝 Tailscale → 同一帳號 → Connected

↓

外出：開 Home Gallery → 開啟 Tailscale → 複製 PC 的 100.x

↓

返回 App → 貼上 →「儲存 Tailscale IP 並重試」

↓

之後外出：開 Tailscale → 開 App 即可（看完可關 Tailscale／離開 App）

```
