外出用 WebDAV 連回家中相簿

Home Gallery · NAS + DDNS／公網 IP + HTTPS 埠

適用：在家 Wi‑Fi 已可連 NAS，外出要用 HTTPS WebDAV。Windows PC 請改用 Tailscale。

繁體中文

什麼時候用 WebDAV？

  • 人在家、連家中 Wi‑Fi → 不必開 WebDAV 遠端；走區網 SMB
  • 外出、NAS 可開 HTTPS WebDAV + DDNS／公網 IP → 用 WebDAV
  • 外出、Windows PC → 用 Tailscale
  • 已用 OpenVPN 等連進家中區網 → 通常不必再開

1. NAS 摘要

  1. 啟用 WebDAV HTTPS（Synology 常見埠 5006）
  2. 準備 DDNS（例如 xxx.synology.me）或公網 IP
  3. 確認路由器／防火牆已放行該埠（依環境）

2. Home Gallery

  1. 先在家中 Wi‑Fi把主機與家中相簿設好
  2. 設定 → 主機連線管理 → 編輯 → 遠端存取選 WebDAV
  3. 填外網主機（DDNS／公網 IP）與埠；多數家用 NAS 可勾選允許自簽憑證
  4. 測試連線 → 儲存

區網 IPv4 請維持 192.168.x。IPv6 欄位僅在「啟用 IPv6」開啟時顯示（預設關閉）；外出以你填的 WebDAV 主機為準。

3. 外出

  • 關家中 Wi‑Fi → 開家中相簿，應以 WebDAV 連線
  • 連不上：檢查 DDNS、埠、NAS WebDAV 是否啟用、帳密與權限

對外開放 WebDAV 請用強密碼；不需要外出時遠端存取請維持「無」。

English

When to use WebDAV

  • At home on Wi‑Fi → SMB on the LAN; no remote WebDAV needed
  • Away, NAS with HTTPS WebDAV + DDNS/public IP → use WebDAV
  • Away, Windows PC → use Tailscale
  • Already on a home-LAN VPN → usually neither is required

1. NAS (summary)

  1. Enable WebDAV over HTTPS (Synology often uses port 5006)
  2. Set up DDNS or note your public IP
  3. Allow the port through your router/firewall as needed

2. Home Gallery

  1. On home Wi‑Fi, finish the host and home album setup
  2. Settings → Host connections → Edit → remote access WebDAV
  3. Enter public host (DDNS/IP) and port; allow untrusted certs if your NAS uses a self-signed cert
  4. Test connection → Save

Keep LAN IPv4 as 192.168.x. The IPv6 field appears only when Enable IPv6 is on (off by default); away access uses the WebDAV host you entered.

3. Away

  • Turn off home Wi‑Fi → open the home album; it should connect via WebDAV
  • If it fails: check DDNS, port, WebDAV service, credentials and share permissions

Exposing WebDAV to the internet requires a strong password. If you do not need away access, leave remote access on None.

日本語 — 外出用 WebDAV 家に戻ったときのアルバム（取扱説明書）

日本語専用の画面がない場合は、英語版スクリーンショットを表示しています。

適用：ホームギャラリー はすでに自宅で Wi‑Fi を使って NAS（Synology／QNAP など）に接続でき、外出時（モバイルデータ／外部ネットワーク Wi‑Fi）は HTTPS WebDAV で同じ自宅のアルバムを閲覧する必要があります。

和エリアネットワーク構築の違い： Synology／QNAP 建置 家で開く方法を教える SMB 共有；このページでは、外出時に WebDAV（パブリックIP または DDNS）を使う方法を教える。
Windows PC？ 多くの家庭用 Windows には HTTPS WebDAV が標準で入っていません；外出時は Tailscale を使用してください。

約 10～20 分間（DSM／QTS がすでにログインでき、DDNS または公共ネットワークのアドレスを知っている場合を想定）。

1. いつ WebDAV を使うのか？

| シチュエーション | 提案 |

|------|------|

| 人が家にいる時、携帯が家に接続 Wi‑Fi | 開く必要はなし WebDAV 遠隔操作；LAN SMB に接続するだけ |

| 外出、NAS 開けることができます HTTPS WebDAV + DDNS／公衆ネットワークアドレス | 使用 WebDAV（このページ） |

| 外出時、Windows PC を SMB ホスト として | Tailscale を使用 |

| すでに OpenVPN／WireGuard などで自宅のネットワークに接続済み | 通常、再度 WebDAV／Tailscale を開く必要はなく、ネットワーク IPv4 を維持すればよい |

家の中では Wi‑Fi は依然として SMB に接続されています；家の範囲のネットワークを離れたときにのみ、アプリはあなたが設定した WebDAV に切り替わります。

2. 開始前に確認してください

  • 家中Wi‑Fiで、アプリはすでにそのホストに接続でき、家中のアルバムを開くことができます
  • NAS 有効化済み WebDAV（HTTPS）（Synology 一般的なポート 5006）
  • 利用可能な DDNS ホスト名（例：你的名稱.synology.me）または固定／既知のパブリックIP
  • ルーター／ファイアウォールが外部ネットワークから NAS の HTTPS WebDAV ポート（一般的な TCP 5006; 詳細はお使いの機種と通信環境による）への接続を許可している
  • SMB と同じセットの NAS アカウント情報を使用する（またはそのアカウントが WebDAV と共有する権限を持っていることを確認する）

App の WebDAV フィールドに完全な URL パス（例：https://…/photo）を貼らないでください。 ホスト名または IP のみを入力し、ポートは別に入力してください。共有とフォルダは自宅のアルバムで決定されます。

3. NAS で WebDAV を有効にする（概要）

Synology（DSM）

  1. コンソール → ファイルサービス → WebDAV（または高度／アプリケーションの中の WebDAV）
  2. WebDAV を有効にし、HTTPS を有効にする
  3. HTTPS ポート を記入します（デフォルトは多くの場合 5006 です）
  4. 適用

QNAP（QTS／QuTS）

  1. コントロールパネル → ネットワークとファイルサービス → WebDAV に関連する項目を見つける
  2. WebDAV／HTTPSを有効にして、ポート番号を記録する
  3. 適用

（メニュー名はバージョンによって若干異なる場合があります；コントロールパネルで「WebDAV」を検索してください。）

DDNS（提案）

もしグローバルIPが変わる場合は、NASまたはルーターでDDNSを有効にしてください（例えば Synology DDNS：xxx.synology.me）。その後、アプリにこのホスト名を入力するだけで済みます。

4. ホームギャラリー でリモートアクセスを設定する

  1. まず自宅で Wi‑Fiルーターと自宅のアルバムが使用可能か確認する
  2. もっと見る → 設定 → ホスト接続管理 → 該当のホストを編集
  3. リモートアクセスで WebDAV を選択
  4. WebDAV 外部ネットワークホスト：DDNS またはパブリックIPを入力（例：jasoncsnas.synology.me）
  5. WebDAV ポート：HTTPS ポートを入力（例：5006）
  6. （ほとんどの家庭用 NAS）信頼されていない HTTPS 証明書を許可する にチェックを入れる
  7. アプリは すべての証明書を無条件に信頼することはありません。まず システムの信頼 を使用し、失敗した場合に初めて「そのホスト」に対して TOFU 証明書ピンニング（最初の接続に成功した際の証明書のフィンガープリントを記憶）を行います。
  8. 若 NAS 後に証明書を交換したことで接続に失敗した場合：このスイッチを一度オフにして再度オンにする（または WebDAV ホスト名を変更する）ことで、古いピン止めをクリアして再試行してください。
  9. 接続テスト → 成功したら 保存

ローカルネットワーク IPv4 家の 192.168.x.x（またはスキャンしたアドレス）を維持し、WebDAV の外部ネットワークホストとは別に入力してください。
IPv6 フィールド： 設定 → ホスト接続管理で 有効 IPv6 をオンにした場合のみ表示（デフォルトはオフ）。外出 WebDAV はあなたが入力した外部ネットワークホスト／DDNS を基準とします。

5. 外出の使い方

  1. 家の中の Wi‑Fi を閉じる（または家のネットワークを離れる）、モバイルデータ／外部ネットワーク Wi‑Fi に切り替える
  2. 対応する家のアルバムを開く
  3. アプリは WebDAV 接続であるべきである；閲覧、再生（バージョン機能に応じて）および既存のバックアッププロセスが可能である

もし接続できない場合：

  • DDNS 携帯ブラウザで解析できますか？ポートは正しいですか？
  • NAS WebDAV HTTPS はまだ有効ですか？
  • ルーターはそのポートを開放していますか？
  • アカウントとパスワードはネットワークと同じですか、またその共有に権限はありますか？
  • 設定 → 診断ログのエクスポート に進み、ログ内で transport=WebDAV via=webdavHost を検索できます

外出体験の期待（行動データ）

  • 接続：アプリは優先的に IPv4 を使用します（DDNS が同時に IPv6 を返す場合、ネットワークが不安定な環境では IPv6 がよく止まります）。
  • フォルダ表紙／リスト：各階層のフォルダはすべて NAS にリストを一度取得する必要があります；表紙のコラージュはさらに下のサブフォルダを参照する可能性があり、外部ネットワークでの体感速度は内部ネットワーク SMB より遅くなることが予想されます。
  • 写真のサムネイル：まずファイルヘッダー／EXIFを読みます；失敗した場合は最大約 2 MB の先頭部分（大きな画像全体を避けるため）
  • 動画再生：本機 HTTP ブリッジ経由で、単一範囲 Range のストリーミングが主です；外部ネットワークのスループットは自宅のアップロード速度とモバイルネットワークの制限を受けるため、再生開始やシークはローカルネットワークより遅くなる場合があります。
  • トラブルシューティング：一般ユーザーは 設定 → 診断ログをエクスポート（transport=WebDAV … を含む）を使用してください。正式版では logcat に WebDAV の Range／TLS の詳細は表示されません。

6. Tailscale とどう選ぶ？

| | WebDAV | Tailscale |

|--|------------|---------------|

| 適合 | すでに開かれた HTTPS WebDAV の NAS | Windows PC または WebDAV を開けないホスト |

| アプリ設定 | リモートアクセス = WebDAV；DDNS／パブリックIP + ポートを入力 | リモートアクセス = Tailscale；100.xを入力 |

| 追加アプリ | 通常不要 | 携帯と本体の両方にインストール Tailscale |

同一ホストでは一つのリモート方式を選んでください；二つの方式を混用しないでください。

7. 安全の注意（必ずお読みください）

  • 外部に公開する WebDAV ポートは、ファイルサービスをインターネットにさらすことに相当します。強力なパスワードを使用し、必要に応じて独立したアカウントを作成してください。
  • できるだけ HTTPS を使用してください。家庭用自己署名証明書は「信頼されていない証明書を許可する」にチェックを入れてください：システムで信頼＋ホストにピン留め であり、任意の証明書を信頼するわけではありません。詳細は §4 を参照してください。
  • 外出してアクセスする必要がない場合、リモートアクセスは 無 のままにし、家庭内のみ Wi‑Fi で使用してください。

한국어 — 외출용 WebDAV 집으로 돌아가는 앨범 연결 (사용 설명서)

한국어 전용 화면이 없으면 영어 스크린샷을 사용합니다.

적용: 홈 갤러리 이미 집에서 Wi‑Fi NAS(Synology/QNAP 등)에 접속할 수 있으며, 외출 시(모바일 데이터/외부 네트워크 Wi‑Fi) HTTPS WebDAV를 사용하여 같은 집 사진 앨범을 볼 수 있습니다.

지역 네트워크 구축의 차이점: Synology／QNAP 建置 집에서 여는 방법을 가르쳐 주고 SMB 공유; 이 페이지에서는 외출 시 WebDAV(공용 IP 또는 DDNS) 사용 방법을 가르쳐 줍니다.
Windows PC? 대부분 가정용 Windows에는 기본적으로 HTTPS WebDAV이 없습니다; 외출 시에는 Tailscale를 사용하세요.

약 10~20분 정도 소요됩니다（가정: DSM/QTS에 이미 로그인할 수 있고, DDNS 또는 공용 네트워크 주소를 알고 있는 경우).

1. WebDAV을 언제 사용하나요?

| 상황 | 제안 |

|------|------|

| 사람이 집에 있을 때, 휴대폰이 집과 연결 Wi‑Fi | 할 필요 없음 원격 WebDAV 켜기; 로컬 네트워크 SMB 접속만 하면 됨 |

| 외출, NAS 열 수 있음 HTTPS WebDAV + DDNS／공용 네트워크 주소 | 사용 WebDAV(이 페이지) |

| 외출, Windows PC를 SMB 주 기기로 | Tailscale 사용 |

| 이미 OpenVPN／WireGuard 등으로 집 내부 네트워크에 연결 | 보통은 WebDAV／Tailscale를 다시 열 필요 없음; 네트워크 IPv4를 유지하면 됨 |

집에서는 Wi‑Fi 여전히 SMB로 연결됩니다; 집 지역망을 벗어날 때만, 앱이 설정한 WebDAV로 바뀝니다.

2. 시작하기 전에 확인하세요

  • 집 안 Wi‑Fi 아래, 앱이 이미 해당 호스트에 연결되어 집 안 앨범을 열 수 있음
  • NAS 이미 활성화됨 WebDAV(HTTPS) (Synology 일반 포트 5006)
  • 사용 가능한 DDNS 호스트 이름(예: 你的名稱.synology.me) 또는 고정/알 수 있는 공용 IP
  • 라우터/방화벽이 외부 네트워크에서 NAS의 HTTPS WebDAV 포트에 접속할 수 있도록 허용했는지 확인（일반적인 TCP 5006; 자세한 내용은 사용 중인 장치 모델과 통신 환경에 따라 다름）
  • SMB와 같은 그룹의 NAS 계정 정보 사용(또는 해당 계정이 WebDAV와 공유할 권한이 있는지 확실한 경우)

앱의 WebDAV 칸에 전체 URL 경로를 붙이지 마세요 (예: https://…/photo). 호스트 이름 또는 IP만 입력하고, 포트는 따로 입력하세요; 공유 및 폴더는 집 사진첩에서 결정됩니다.

3. NAS에서 WebDAV 활성화(요약)

Synology（DSM）

  1. 콘솔 → 파일 서비스 → WebDAV(또는 고급/응용 프로그램에서 WebDAV)
  2. WebDAV을 활성화하고, HTTPS도 활성화하세요
  3. HTTPS 포트를 기록하세요(기본값은 대부분 5006)
  4. 적용

QNAP（QTS／QuTS）

  1. 콘솔 → 네트워크 및 파일 서비스 → WebDAV 관련 항목 찾기
  2. WebDAV/HTTPS 활성화, 포트 번호를 기록
  3. 적용

（메뉴 이름은 버전마다 약간 다를 수 있습니다; 콘솔에서 'WebDAV'를 검색하면 됩니다.）

DDNS（권장）

공인 IP가 변경될 경우, NAS 또는 라우터에서 DDNS를 활성화하세요(예: Synology DDNS: xxx.synology.me), 그 후 앱에 이 호스트 이름을 입력하면 됩니다.

4. Home Gallery에서 원격 액세스 설정

  1. 먼저 집에서 Wi‑Fi 주기기와 집 앨범이 사용 가능한지 확인하십시오
  2. 더보기 → 설정 → 호스트 연결 관리 → 해당 호스트 편집
  3. 원격 접속 선택 WebDAV
  4. WebDAV 외부 네트워크 호스트: DDNS 또는 공인 IP 입력 (예: jasoncsnas.synology.me)
  5. WebDAV 포트：HTTPS 포트 입력 (예: 5006)
  6. (대다수 가정용 NAS) 신뢰할 수 없는 HTTPS 인증서 허용 선택
  7. 앱은 모든 인증서를 무조건 신뢰하지 않습니다. 먼저 시스템 신뢰를 사용하고, 실패 시에만 해당 호스트에 대해 TOFU 인증서 고정을 수행합니다(처음으로 성공적으로 연결된 인증서 지문을 기억함).
  8. NAS 이후 인증서를 교체하여 연결 실패가 발생한 경우: 이 스위치를 껐다가 다시 켜거나 (또는 WebDAV 호스트 이름을 변경) 이전 고정 항목을 삭제한 후 다시 시도하십시오.
  9. 연결 테스트 → 성공하면 저장

구역망 IPv4 집에서 192.168.x.x(또는 스캔한 주소)를 유지하고, WebDAV 외부망 호스트와는 따로 기입하세요.
IPv6 필드: 설정 → 호스트 연결 관리에서 IPv6 활성화를 켠 경우에만 표시됩니다(기본값은 끔). 외부 WebDAV는 사용자가 입력한 외부 네트워크 호스트/DDNS를 기준으로 합니다.

5. 외출 시 사용 방법

  1. 집에서 Wi‑Fi를 끄거나(또는 집 내 네트워크를 떠나), 모바일 데이터/외부 네트워크 Wi‑Fi를 사용
  2. 해당 집 사진첩 열기
  3. 앱은 WebDAV 연결을 사용해야 하며; 버전에 따라 탐색, 재생 및 기존 백업 프로세스를 수행할 수 있습니다

연결할 수 없는 경우:

  • DDNS 휴대폰 브라우저에서 해석할 수 있나요? 포트가 올바른가요?
  • NAS WebDAV HTTPS 여전히 활성화되어 있습니까?
  • 라우터가 해당 포트를 열어주었나요?
  • 계정과 비밀번호가 로컬 네트워크와 동일하며, 해당 공유 폴더에 권한이 있나요?
  • 설정 → 진단 기록 내보내기로 이동한 후, 로그에서 transport=WebDAV via=webdavHost을 검색할 수 있습니다

외출 체험 기대(모바일 데이터)

  • 연결: 앱은 우선 IPv4을 사용합니다 (DDNS이 동시에 IPv6로 응답할 경우, 네트워크가 약할 때 IPv6이 자주 멈춥니다).
  • 폴더 표지/목록: 각 계층의 폴더는 NAS 에 일람을 한 번 요청해야 합니다; 표지 콜라주는 하위 폴더를 더 탐색할 수도 있으며, 외부 네트워크 체감 속도는 내부 네트워크 SMB 보다 느릴 수 있으며, 이는 예상되는 사항입니다.
  • 사진 축소판: 먼저 파일 헤더/EXIF를 읽습니다; 실패할 경우 최대 약 2 MB 전치사(전체 큰 이미지를 피하기 위해)
  • 영상 재생: 본 기기 HTTP bridge를 통해, 단일 구간 범위 스트리밍을 주로 사용합니다; 외부 네트워크 속도는 집의 업로드와 모바일 네트워크 제한을 받기 때문에, 재생 시작과 탐색(seek)은 로컬 네트워크보다 느릴 수 있습니다.
  • 문제 해결: 일반 사용자는 설정 → 진단 기록 내보내기(transport=WebDAV … 포함)를 사용하세요. 정식 버전에서는 logcat에 WebDAV Range/TLS 세부 정보가 표시되지 않습니다.

6. Tailscale과 어떻게 선택할까?

| | WebDAV | Tailscale |

|--|------------|---------------|

| 적합 | 이미 열린 HTTPS WebDAV 의 NAS | Windows PC 또는 WebDAV 를 열 수 없는 기기 |

| 앱 설정 | 원격 접속 = WebDAV; DDNS/공용 IP + 포트 입력 | 원격 접속 = Tailscale; 100.x 입력 |

| 추가 앱 | 일반적으로 필요 없음 | 휴대폰과 메인 장치 모두 설치 Tailscale |

같은 호스트에서는 한 가지 원격 방식을 선택하면 됩니다; 두 가지 방식을 혼용하지 마세요.

7. 안전 알림(반드시 읽으세요)

  • 외부에 포트 WebDAV를 개방하는 것은 파일 서비스를 인터넷에 노출하는 것과 같습니다; 강력한 비밀번호를 사용하고 필요시 별도의 계정을 사용하세요.
  • 가능한 한 HTTPS을 사용하세요. 가정용 자체 서명 인증서는 '신뢰할 수 없는 인증서 허용'을 선택하세요: 시스템 신뢰 + 호스트 고정 방식으로, 임의의 인증서를 신뢰하는 것이 아닙니다. 자세한 내용은 §4를 참조하세요.
  • 외부에서 접속할 필요가 없다면, 원격 접속은 없음으로 유지하고, 집에서만 Wi‑Fi 사용하십시오.

```
NAS：啟用 WebDAV HTTPS → 記下埠（常為 5006）

路由器／防火牆已放行該埠（依環境）

App：遠端存取 = WebDAV → 填主機＋埠 → 測試 → 儲存

外出：關家中 Wi‑Fi → 開家中相簿確認可連

```
