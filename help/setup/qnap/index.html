QNAP NAS 開通共用

QTS 5.x／QuTS · 約 15～25 分鐘 · 截圖待補

繁體中文English 日本語 한국어排查

步驟摘要

  1. 控制台 → 網路與檔案服務 → Win/Mac/NFS/WebDAV → Microsoft 網路：啟用 Microsoft 網路檔案服務 → 套用（勿開 SMB1）
  2. 控制台 → 權限設定 → 共用資料夾：新增或選取共用
  3. 資料夾權限：建議手機帳號 RW（上傳／移動／編輯／備份需要）；訪客建議 Deny
  4. File Station 放入相片（可選）
  5. 記下名稱／IP／帳密
  6. 同一 Wi‑Fi → Home Gallery 連線 → 選共用 → 完成

完整文字稿：docs/setup-home-storage/qnap.md。第一次連線通常不必開「進階權限／Windows ACL」。
