Home Gallery에 대한 QNAP NAS 공유 활성화

Home Gallery

한국어 전용 화면이 없으면 영어 스크린샷을 사용합니다.

繁體中文 English 日本語 한국어 문제 해결

브라우저로 로그인할 수 있고 QTS/QuTS가 이미 설치되어 있는 경우 약 15~25분 소요됩니다. 이후 Home Gallery은 NAS를 홈 스토리지로 사용할 수 있습니다.

일반적인 QTS 5.x / QuTS hero 제어판 경로에 대해 작성됨(많은 QuTScloud 홈 유닛에서도 일반적임). 레이블이 다를 경우, Microsoft Networking, SMB, 또는 공유 폴더를 검색하세요.
휴대폰은 SMB을 통해 폴더를 읽습니다 (QNAP에서는 종종 이를 Microsoft 네트워킹 / SMB라고 표시합니다).

시작하기 전에

  • NAS 관리 UI가 브라우저에서 열립니다(예: http://NAS-IP:8080 또는 myQNAPcloud / Qfinder를 통해)
  • 당신은 관리자 계정을 가지고 있습니다
  • 전화기와 NAS가 같은 홈 Wi‑Fi / LAN에 있습니다
  • 사진이 저장될 위치 결정: 새 공유(예: FamilyPhotos) 또는 기존 공유의 하위 폴더

단계 1: Microsoft 네트워킹 활성화 (SMB)

  1. QTS / QuTS에 로그인하세요
  2. 제어판을 엽니다
  3. 네트워크 및 파일 서비스를 엽니다
  4. Win/Mac/NFS/WebDAV 열기 (탭 이름은 약간 다를 수 있음)
  5. 마이크로소프트 네트워킹 선택
  6. Microsoft 네트워킹을 위한 파일 서비스 사용 확인
  7. 적용을 클릭하세요

(스크린샷: 윈도우/맥/NFS → 마이크로소프트 네트워킹 → 활성화)

권장 고급 옵션

같은 페이지에서 또는 고급 설정에서:

  • 최대 SMB 버전은 기본값으로 두기 (SMB 2/3)
  • 호환성을 위해 SMB1을 활성화하지 마십시오 (보안 위험; Home Gallery에는 필요하지 않음)
  • SMB 암호화: 처음 설정할 때는 기본값을 그대로 두세요; 강제 암호화가 휴대폰을 차단하면 문제 해결 중에는 완화하세요
  • 서버 설명 / 작업 그룹: 가정에서는 기본값으로 괜찮습니다

2단계: 공유 폴더 생성 또는 확인

  1. 제어판 → 권한 → 공유 폴더
  2. 적절한 공유가 이미 존재하는 경우, 해당 이름을 기록하고 3단계로 이동합니다
  3. 그렇지 않으면 만들기 → 공유 폴더를 선택하고 다음을 설정합니다:
  4. 폴더 이름: 예: FamilyPhotos (앱에서 공유 폴더로 표시됨)
  5. 빈 공간이 있는 볼륨/스토리지 풀
  6. “네트워크 드라이브 숨기기”: 초기 디버깅을 쉽게 하려면 선택하지 않은 상태로 두세요
  7. 공유가 목록에 나타나는지 확인하십시오

(스크린샷: 공유 폴더 목록 / 생성 마법사)

권한이 올바르고 사진이 존재하거나 존재할 예정이라면 Multimedia 또는 homes과 같은 내장 공유도 괜찮습니다.

단계 3: 폴더 권한

  1. 목록에서 주식을 찾으세요
  2. 폴더 권한 열기 (또는 편집 → 권한)
  3. 전화기가 사용할 계정의 경우, RW(읽기/쓰기)를 선호하세요
  4. 업로드, 이동/복사, 편집 및 앨범 백업은 쓰기 권한이 필요합니다; 읽기 전용 권한만 있으면 나중에 종종 실패가 발생합니다
  5. 전화기가 절대 쓰지 않을 경우에만 RO(읽기 전용)를 사용하세요
  6. Guest를 거부로 설정합니다 (권장)
  7. 적용하기

(스크린샷: 폴더 권한)

추천: 휴대폰 전용 사용자

  1. 제어판 → 권한 → 사용자
  2. 사용자를 생성합니다, 예: homegallery
  3. 비밀번호 설정
  4. 정상 사용자 그룹을 사용하세요—관리자가 아닌
  5. 사진 공유에 대해 사용자 RW 또는 RO 권한을 부여합니다
  6. 관리자 비밀번호를 휴대폰에 저장하는 대신 이 계정으로 앱에 로그인하세요

게스트/익명 접근에 의존하지 마세요.

고급 권한 (보통 건너뜀)

공유 폴더 → 고급 권한에서 고급 폴더 권한 및 Windows ACL과 같은 옵션이 있습니다.

첫 홈 갤러리 연결에서는 건너뛰세요; 먼저 공유 수준의 읽기/쓰기·읽기 전용을 작동시키세요.

4단계: 사진을 공유에 올리기 (선택 사항이지만 권장)

  1. 파일 스테이션을 엽니다
  2. 공유 폴더(또는 하위 폴더)를 엽니다
  3. 사진/동영상을 업로드하거나 이동하기

앱에서 홈 앨범을 추가할 때, 이 공유를 선택한 다음 실제로 사진이 들어 있는 폴더를 선택하세요.

5단계: 연결 세부 정보 기록

| 항목 | 어디서 찾을 수 있나요 |

|------|------------------|

| NAS 이름 | 데스크탑 / 제어판 → 시스템 → 시스템 상태; 또는 Qfinder |

| IP 주소 | 네트워크 및 가상 스위치; 라우터 DHCP; 또는 Qfinder |

| 사용자 이름 / 비밀번호 | 3단계에서 생성된 계정 |

만약 탐지가 실패하면, Home Gallery에 IP를 수동으로 입력하세요.

6단계: Home Gallery에 연결하기

  1. 전화가 같은 집에 Wi‑Fi
  2. 홈 → 홈 스토리지 연결 (또는 더보기 → 설정 → 호스트 연결 → SMB 호스트 추가)
  3. 스캔에서 NAS을 선택하거나 IP를 입력하세요
  4. 자격 증명 → 연결 테스트 → 저장
  5. 공유 폴더 → 앨범 폴더 → 완료 선택

앱 세부 정보: user manual §4 (번체 중국어 출처).

완료 체크리스트

  • Microsoft Networking (SMB) 활성화 및 적용됨
  • 공유가 존재함; 계정은 RO 또는 RW; 게스트는 가능하면 거부
  • 전화기와 NAS가 같은 LAN에 있음
  • 앱 연결 테스트 정상; 폴더 열림
  • (백업) 계정은 읽기/쓰기(RW) 입니다

실패할 경우: Troubleshooting.

짧은 FAQ

myQNAPcloud가 필요하신가요? 가정용 LAN에서는 필요하지 않습니다SMB. LAN IP/호스트 이름을 사용하세요.

방화벽 / 보안 센터? 방화벽이 켜져 있는 경우 LAN에서 SMB (TCP 445)에 대한 액세스를 허용하십시오.

QuTS hero vs QTS? 전체적인 흐름은 동일함 (SMB 활성화 → 공유 → 권한 → 앱); 저장소 용어는 다를 수 있음.

5G에서 나갔나요? 집에서는 Wi‑Fi 앱이 여전히 SMB을 사용합니다. 집을 떠나 있을 때는 원격 액세스를 WebDAV (DDNS / 공용 IP + HTTPS 포트)로 설정하세요—webdav.md를 참조하십시오. Windows PC의 경우 Tailscale를 사용하세요.
