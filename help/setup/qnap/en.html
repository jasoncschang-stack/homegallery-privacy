QNAP NAS sharing

QTS 5.x / QuTS · about 15–25 minutes · Screenshots pending

繁體中文English 日本語 한국어Troubleshooting

Steps (summary)

  1. Control Panel → Network & File Services → Win/Mac/NFS/WebDAV → Microsoft Networking: Enable file service → Apply (no SMB1)
  2. Privilege → Shared Folders: create or pick a share
  3. Folder Permissions: prefer RW for the phone user (needed for upload/move/edit/backup); Guest = Deny recommended
  4. Optional: add photos in File Station
  5. Note name / IP / credentials
  6. Same Wi‑Fi → Home Gallery → pick share → Finish

Full draft: docs/setup-home-storage/qnap.en.md. Skip Advanced Permissions / Windows ACL for a first connection.
