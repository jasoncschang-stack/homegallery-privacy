Home GalleryのためにQNAP NAS共有を有効にする

Home Gallery

繁體中文 English 日本語 한국어 トラブルシューティング

すでにQTS/QuTSがインストールされており、ブラウザでサインインできる場合、約15〜25分です。その後、Home GalleryはNASをホームストレージとして使用できます。

一般的な QTS 5.x / QuTS hero コントロールパネルのパス（多くの QuTScloud ホームユニットにも典型的）向けに作成されています。ラベルが異なる場合は、Microsoft Networking、SMB、または 共有フォルダ を検索してください。

＞ 電話は SMB 上のフォルダを読み取ります（QNAP はこれをしばしば Microsoft Networking / SMB とラベル付けします）。

はじめる前に

  • NAS の管理者 UI がブラウザで開きます（例：http://NAS-IP:8080、または myQNAPcloud / Qfinder 経由）
  • あなたは管理者アカウントを持っています
  • 電話とNASは同じホームWi‑Fi / LANにあります
  • 写真の保存場所を決める: 新しい共有フォルダ（例: FamilyPhotos）か、既存の共有フォルダのサブフォルダ

ステップ 1: Microsoft ネットワーキングを有効にする (SMB)

  1. QTS / QuTS にサインイン
  2. コントロールパネル を開きます
  3. ネットワークとファイルサービス を開く
  4. Win/Mac/NFS/WebDAV を開く（タブ名は少し異なる場合があります）
  5. Microsoft ネットワーキング を選択
  6. Microsoft ネットワーキング用のファイルサービスを有効にする にチェックを入れる
  7. 適用 をクリック

(スクリーンショット: Win/Mac/NFS → Microsoft ネットワーキング → 有効にする)

推奨される高度なオプション

同じページまたは詳細設定で：

  • 最大SMBバージョンをデフォルトのままにする (SMB 2/3)
  • 互換性のためにSMB1を有効にしないでください（セキュリティリスク; Home Galleryには必要ありません）
  • SMB 暗号化: 初回設定ではデフォルトのままにしてください；強制暗号化で電話が使えなくなる場合は、トラブルシューティング時に緩めてください
  • サーバーの説明 / ワークグループ: 家ではデフォルトで問題ありません

ステップ2: 共有フォルダを作成または確認する

  1. コントロールパネル → 権限 → 共有フォルダ
  2. 適切な共有が既に存在する場合は、その名前をメモしてステップ3に進んでください
  3. それ以外の場合は 作成 → 共有フォルダー を選択し、次のように設定します:
  4. フォルダ名: 例 FamilyPhotos（アプリでは共有フォルダとして表示されます）
  5. 空き容量のあるボリューム/ストレージプール
  6. 「ネットワークドライブを隠す」：初回デバッグを簡単にするためにチェックを外したままにする
  7. 共有がリストに表示されていることを確認してください

（スクリーンショット：共有フォルダの一覧／作成ウィザード）

権限が正しく、写真が存在する（または存在する予定である）場合、Multimedia や homes のような組み込み共有でも問題ありません。

ステップ 3: フォルダの権限

  1. リストで株式を見つける
  2. フォルダーの権限 を開く（または 編集 → 権限）
  3. 電話で使用するアカウントについては、RW（読み書き） を優先してください
  4. アップロード、移動/コピー、編集、アルバムのバックアップには書き込み権限が必要です；読み取り専用だけでは後で失敗することがよくあります
  5. 電話が書き込みを行わない場合のみ、RO（読み取り専用）を使用してください
  6. ゲストを拒否に設定する（推奨）
  7. 適用する

（スクリーンショット：フォルダの権限）

推奨：電話のみのユーザー

  1. コントロールパネル → 権限 → ユーザー
  2. ユーザーを作成 例: homegallery
  3. パスワードを設定する
  4. 通常のユーザーグループを使用してください—管理者ではなく
  5. 写真の共有に対して、ユーザー RW または RO に権限を付与する
  6. 管理者パスワードを電話に保存する代わりに、アプリでこのアカウントにサインインしてください

ゲスト/匿名アクセスに頼らないでください。

高度な権限（通常はスキップ）

共有フォルダ → 詳細な権限 では、詳細なフォルダ権限や Windows ACL などのオプションがあります。

最初のHome Gallery接続ではそれらをスキップ; まずは共有レベルの読み書き/読み取り専用を動作させる。

ステップ4：写真を共有に入れる（任意だが推奨）

  1. ファイルステーション を開く
  2. 共有フォルダー（またはサブフォルダー）を開きます
  3. 写真やビデオをアップロードまたは移動する

アプリでホームアルバムを追加するときは、この共有を選び、次に実際に写真が入っているフォルダを選んでください。

ステップ5：接続の詳細を記録する

| アイテム | 入手場所 |

|------|------------------|

| NAS 名前 | デスクトップ / コントロールパネル → システム → システムの状態; または Qfinder |

| IPアドレス | ネットワーク & 仮想スイッチ；ルーターDHCP；またはQfinder |

| ユーザー名 / パスワード | ステップ3のアカウント |

もし検出に失敗した場合は、Home GalleryにIPを手動で入力してください。

ステップ6：Home Galleryで接続

  1. 電話は同じ家にWi‑Fi
  2. ホーム → ホームストレージに接続（または その他 → 設定 → ホスト接続 → SMBホストを追加）
  3. スキャンからNASを選択するか、IPを入力してください
  4. 資格情報 → 接続をテスト → 保存
  5. 共有フォルダー → アルバムフォルダー → 完了 を選択

アプリの詳細：user manual §4（繁体字中国語のソース）。

完了チェックリスト

  • Microsoft ネットワーキング (SMB) が有効化され、適用されました
  • 共有は存在する；アカウントはROまたはRW；ゲストはできれば拒否
  • 電話とNASが同じLAN上にある
  • アプリの接続テストが機能する；フォルダが開く
  • （バックアップ）アカウントはRWです

もし失敗した場合：Troubleshooting。

短いFAQ

myQNAPcloudが必要ですか？ ホームLANには不要ですSMB。LANのIP/ホスト名を使用してください。

ファイアウォール / セキュリティセンター？ ファイアウォールがオンの場合、SMB (TCP 445) へのLANアクセスを許可します。

QuTS hero と QTS の違い？ 全体の流れは同じ（SMB を有効にする → 共有 → 権限 → アプリ）；ストレージの用語は異なる場合があります。

5Gで外出中ですか？ 自宅Wi‑FiではアプリはまだSMBを使用します。自宅外では、リモートアクセスをWebDAVに設定してください（DDNS / 公開IP + HTTPSポート）—webdav.mdを参照してください。Windows PCの場合は、Tailscaleを使用してください。
