家中儲存連線排查

已開過共用，但 App 連不上時使用

繁體中文English 日本語 한국어

繁體中文

建置指南：Windows 11 · Synology · QNAP

A. 完全找不到主機

  1. 手機是否在家中 Wi‑Fi？（行動數據通常掃不到僅 IPv4 的家用電腦）
  2. 是否同一網路？（訪客 Wi‑Fi／VPN 可能隔離裝置）
  3. Windows 網路是否為私人？
  4. 電腦／NAS 是否睡眠或關機？
  5. 改用手打 IPv4（電腦執行 ipconfig）
  6. 防火牆：私人網路上允許「檔案和印表機共用」

B. 看得到主機，但帳密失敗

  1. 使用 Windows／NAS 登入密碼，不是 PIN
  2. Microsoft 帳戶可試 MicrosoftAccount\信箱；或改用本機／NAS 專用帳
  3. 確認該使用者在共用權限清單中

C. 能登入，但看不到資料夾

  1. 選對共用名稱
  2. 再往下一層選到實際放照片的資料夾
  3. 檔案是否已放進該共用

D. 能瀏覽，但上傳／備份失敗（只讀）

  1. 共用權限需含變更／讀寫
  2. Windows 亦檢查 NTFS「安全性」是否允許寫入
  3. 磁碟空間是否已滿

E. 外出（行動數據）連不上

若尚未設定遠端方式，多數家用 PC／NAS 在行動數據下本來就連不到 SMB——這是預期行為。若要外出瀏覽：

  1. NAS：依 WebDAV 手冊 啟用 HTTPS WebDAV，在 App 遠端存取選 WebDAV，填 DDNS／公網 IP 與埠
  2. Windows PC：依 Tailscale 手冊 安裝並登入同一帳號，在 App 貼上 100.x
  3. 若已用 OpenVPN 等連進區網，維持區網 IPv4 即可，不必再開 WebDAV／Tailscale

English

Setup guides: Windows 11 · Synology · QNAP

A. Host not found

  1. Phone on home Wi‑Fi? (Cellular usually cannot reach IPv4-only home PCs)
  2. Same network? (Guest Wi‑Fi / VPN may isolate devices)
  3. Windows network profile Private?
  4. PC/NAS asleep or off?
  5. Enter IPv4 manually (ipconfig)
  6. Firewall: allow File and Printer Sharing on Private

B. Host found, login fails

  1. Use the account password, not PIN
  2. Try MicrosoftAccount\email or a dedicated local/NAS user
  3. Confirm the user is on the share permissions list

C. Logged in, folder missing

  1. Correct share name?
  2. Drill into the folder that actually holds photos
  3. Files copied into that share?

D. Browse works, upload/backup fails (read-only)

  1. Share needs Change / Read-Write
  2. On Windows, also check NTFS Security ACLs
  3. Disk full?

E. Works at home, fails on mobile data

Without a remote-access method, most home PCs/NAS are unreachable on cellular via SMB—that is expected. To browse away from home:

  1. NAS: follow the WebDAV guide (HTTPS WebDAV + DDNS/public IP + port in the app)
  2. Windows PC: follow the Tailscale guide, then paste 100.x in the app
  3. If you already use OpenVPN (or similar) into the LAN, keep the LAN IPv4—no WebDAV/Tailscale needed

Windows の構築手順：windows-11.md

Synology 構築手順：synology.md

QNAP 構築手順：qnap.md

A. ホストがまったく見つかりません

順番にチェック：

  1. 携帯電話は家にありますか Wi‑Fi？

行動データ（5G／4G）を使用する場合、通常、家庭内の IPv4 のみのコンピュータは検出できません。家庭内の Wi‑Fi に接続してください。

  1. 携帯電話とコンピュータは同じネットワークですか？

訪問者 Wi‑Fi、異なる SSID、会社／学校の VPN は、デバイスを隔離する可能性があります。両方とも「普段の家庭用」の方 Wi‑Fi に接続すべきです。

  1. コンピューターネットワークは「私的」ですか？

Windowsのガイドステップ1を参照してください。パブリックネットワークは通常、探索と共有をブロックします。

  1. コンピュータはスリープまたはシャットダウンしていますか？

睡眠後 SMB が中断されます；起きているか電源に接続し、睡眠時間を調整してください。

  1. 手打ちIPに切り替え

コンピュータで ipconfig を実行し、IPv4（例：192.168.x.x）をアプリ「手動でホスト入力」に入力します。

もしIPに接続できるが、名前が見つからない場合：大半は探索／ファイアウォールの問題で、接続自体は可能な場合があります。

  1. ファイアウォール

「ファイルとプリンターの共有」がプライベートネットワークで許可されていることを確認してください（Windows ガイドのステップ5）。

B. ホストにアクセスできるが、アカウント情報が失敗する

  1. 使用 Windows のログインパスワード、PIN ではなく、Microsoft アカウントのウェブパスワードでもない（もし一致しない場合）。
  2. Microsoft アカウントで試す：MicrosoftAccount\你的信箱；それでも失敗する場合は、共有用にローカルアカウントを作成する。
  3. 該当ユーザーが「詳細共有 → 権限」に追加されていることを確認する。
  4. 「パスワード保護された共有」がオンになっていることを確認し、パスワード付きのアカウントを入力してください。

C. ログインはできるが、期待したフォルダ／写真が見えない

  1. 共有名（Share）が正しく選ばれているか確認し、他のドライブの共有ではないことを確認してください。
  2. アプリでさらに下の階層に進み、実際に写真を入れているフォルダを選びます。
  3. ファイルはまだローカルの「このデバイスのみ」のパスにあり、共有フォルダには入っていません。

D. 閲覧は可能だが、アップロード／バックアップに失敗（読み取り専用）

  1. 共有権限には 変更（書き込み）を含める必要があり、読み取りだけではいけません。
  2. NTFS の「セキュリティ」タブでも、そのユーザーがそのフォルダーに書き込みできるようにする必要がある（少数の環境では「共有権限」だけを変更しても不十分）。
  3. ディスクが満杯でないか、またはフォルダが他のプログラムによってロックされていないか。

E. 外出（行動データ）に接続できない

  1. ほとんどの家庭用 PC／NAS はモバイルデータでは本来SMBに接続できません——まだリモート設定をしていない場合、これは予想される動作です。
  2. NAS： WebDAV 使用手冊 に従って HTTPS WebDAV を有効化し、App のリモートアクセスで WebDAV を選択し、DDNS／パブリック IP とポートを入力してください。
  3. Windows PC（または開けない場合 WebDAV）：Tailscale 使用手冊 に従って、PC と携帯に Tailscale をインストールし、アプリに PC の 100.x を入力してください。
  4. もしすでに OpenVPN などで自宅のネットワークに接続している場合は、ネットワーク IPv4 が正しいことを確認すればよく、WebDAV／Tailscale を開く必要はありません。
  5. 初回設定 Tailscale：Tailscale から IP をコピーして App に戻った後、まず貼り付けして「Tailscale IP を保存して再試行」を押してください。戻っただけで自動的に接続されることは期待しないでください。
  6. WebDAV 接続済みだがサムネイル／カバーの読み込みが遅い：モバイルデータ下でよく見られる現象（webdav.md §5「外出体験の期待」を参照）；まずは自宅のアップロード帯域とDDNS／ポートの安定性を確認してください。

外出する場合は WebDAV（NAS）または Tailscale（Windows）を使用してください。

F. 問題を報告する際は添付してください

ご協力いただく際には、以下をご提供ください：

  • アプリのバージョン、携帯電話の機種、Androidのバージョン
  • 保存タイプ：Windows 11 / Synology / QNAP / その他
  • 現象：スキャンできない / アカウントやパスワードが間違っている / 読み取り専用 / 外出先で接続できない
  • リモート方式：なし / WebDAV / Tailscale（ある場合）
  • （オプション）設定 → 診断ログをエクスポート

한국어 — 가정 내 저장 연결 점검

한국어 전용 화면이 없으면 영어 스크린샷을 사용합니다.

적용: 컴퓨터/NAS에서 이미 공유를 열었지만 홈 갤러리 호스트를 찾을 수 없음, 로그인 실패, 볼 수는 있지만 열 수 없음, 또는 백업 불가(쓰기 실패) 경우.

Windows 설치 단계: windows-11.md

Synology 구축 단계: synology.md

QNAP 구축 단계: qnap.md

A. 호스트를 전혀 찾을 수 없음

순서대로 점검:

  1. 휴대폰이 집에 있나요 Wi‑Fi?

모바일 데이터(5G/4G)를 사용할 때, 보통 집에서 IPv4만 있는 컴퓨터는 검색되지 않습니다. 집에 있는 Wi‑Fi로 연결해 주세요.

  1. 휴대폰과 컴퓨터가 같은 네트워크에 있나요?

방문객 Wi‑Fi, 서로 다른 SSID, 회사/학교 VPN은 모두 장치를 격리할 수 있습니다. 양쪽 모두 '평상시 가정용' 그 그룹 Wi‑Fi에 연결해야 합니다.

  1. 컴퓨터 네트워크는 '개인'인가?

Windows 안내 1단계를 참조하십시오. 공용 네트워크는 종종 탐색 및 공유를 차단합니다.

  1. 컴퓨터가 절전 모드/종료 상태인가요?

수면 후 SMB가 중단됩니다; 깨어 있거나 전원을 연결하고 수면 시간을 조절하세요.

  1. 손으로 IP 입력으로 변경

컴퓨터에서 ipconfig를 실행하고, IPv4(예: 192.168.x.x)를 App '수동으로 호스트 입력'에 입력합니다.

만약 IP로 연결은 가능하지만 이름이 검색되지 않는다면: 대부분 탐색/방화벽 문제일 수 있으며, 연결 자체는 이미 가능할 수 있습니다.

  1. 방화벽

개인 네트워크에서 '파일 및 프린터 공유'가 허용되어 있는지 확인하십시오(Windows 안내 5단계).

B. 호스트는 보이지만 계정과 비밀번호 실패

  1. Windows 로그인 비밀번호를 사용하세요. PIN이 아니며, Microsoft 계정 웹 비밀번호도 아닙니다(일치하지 않는 경우).
  2. Microsoft 계정으로 시도: MicrosoftAccount\你的信箱; 그래도 실패하면 로컬 계정을 만들어 공유용으로 사용.
  3. 해당 사용자가 '고급 공유 → 권한'에 추가되어 있는지 확인합니다.
  4. '암호로 보호된 공유'가 켜져 있는지 확인하고, 입력한 계정에 암호가 있는지 확인하세요.

C. 로그인은 할 수 있지만, 예상한 폴더/사진을 볼 수 없음

  1. 공유 이름(Share)을 제대로 선택했는지 확인하세요, 다른 드라이브 공유가 아닌지 확인하세요.
  2. 앱에서 한 단계 더 내려가 실제로 사진을 넣은 폴더를 선택합니다.
  3. 파일이 여전히 이 장치의 '이 장치만' 경로에 있으며, 공유 폴더에 넣지 않았는지 여부.

D. 열람은 가능하지만 업로드/백업 실패(읽기 전용)

  1. 공유 권한에는 변경(쓰기)이 포함되어야 하며, 읽기만 있어서는 안 됩니다.
  2. NTFS '보안' 탭에서도 해당 사용자가 해당 폴더에 쓰기 권한을 허용해야 합니다(일부 환경에서는 '공유 권한'만 변경하는 것으로는 충분하지 않습니다).
  3. 디스크가 가득 찼거나, 폴더가 다른 프로그램에 의해 잠겨 있는지 확인하십시오.

E. 외출(모바일 데이터) 연결 불가

  1. 대다수 가정용 PC/NAS는 이동 데이터로는 원래 SMB에 연결되지 않습니다——원격 방식이 아직 설정되지 않았다면, 이것은 예상되는 동작입니다.
  2. NAS： WebDAV 使用手冊에 따라 HTTPS WebDAV를 활성화하고, 앱 원격 액세스에서 WebDAV를 선택한 후 DDNS/공용 IP와 포트를 입력하세요.
  3. Windows PC（또는 WebDAV를 열 수 없는 경우）：Tailscale 使用手冊에 따라 PC와 휴대폰에 Tailscale를 설치하고, 앱에 PC의 100.x를 입력하세요.
  4. 만약 이미 OpenVPN 등으로 집안 네트워크에 연결했다면, 네트워크 IPv4가 정확한지만 확인하면 되고, WebDAV/Tailscale를 다시 열 필요는 없다.
  5. 최초 설정 Tailscale: Tailscale에서 IP를 복사한 후 앱으로 돌아오면, 먼저 붙여넣고 'IP Tailscale 저장 후 재시도'를 눌러야 하며, 돌아오기만 하면 자동으로 연결될 것이라고 기대하지 마세요.
  6. WebDAV 이미 연결되었으나 썸네일/커버가 매우 느림: 모바일 데이터 환경에서 흔히 나타나는 현상(참조 webdav.md §5『외출 체험 기대』); 먼저 가정의 업로드 대역폭과 DDNS/포트의 안정성을 확인하십시오.

외출 시 WebDAV(NAS) 또는 Tailscale(Windows)를 사용하세요.

F. 문제 보고 시 첨부 부탁드립니다

편리하게 도움을 드리려면 다음을 제공해 주세요:

  • 앱 버전, 휴대폰 모델, 안드로이드 버전
  • 저장 유형: Windows 11 / Synology / QNAP / 기타
  • 현상: 스캔 불가 / 계정 비밀번호 오류 / 읽기 전용 / 외출 시 연결 불가
  • 원격 방식: 없음 / WebDAV / Tailscale(있는 경우)
  • (선택) 설정 → 진단 기록 내보내기
