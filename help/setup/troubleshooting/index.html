家中儲存連線排查

已開過共用，但 App 連不上時使用

繁體中文

建置指南：Windows 11 · Synology · QNAP

A. 完全找不到主機

  1. 手機是否在家中 Wi‑Fi？（行動數據通常掃不到僅 IPv4 的家用電腦）
  2. 是否同一網路？（訪客 Wi‑Fi／VPN 可能隔離裝置）
  3. Windows 網路是否為私人？
  4. 電腦／NAS 是否睡眠或關機？
  5. 改用手打 IPv4（電腦執行 ipconfig）
  6. 防火牆：私人網路上允許「檔案和印表機共用」

B. 看得到主機，但帳密失敗

  1. 使用 Windows／NAS 登入密碼，不是 PIN
  2. Microsoft 帳戶可試 MicrosoftAccount\信箱；或改用本機／NAS 專用帳
  3. 確認該使用者在共用權限清單中

C. 能登入，但看不到資料夾

  1. 選對共用名稱
  2. 再往下一層選到實際放照片的資料夾
  3. 檔案是否已放進該共用

D. 能瀏覽，但上傳／備份失敗（只讀）

  1. 共用權限需含變更／讀寫
  2. Windows 亦檢查 NTFS「安全性」是否允許寫入
  3. 磁碟空間是否已滿

E. 在家可以、出門用 5G 不行

多數僅 IPv4 的家用 PC／NAS 在行動數據下本來就連不到——這是預期行為。若要外出瀏覽：

  1. 依 Tailscale 手冊 在 PC 與手機安裝並登入同一帳號
  2. 在 App 填入／貼上 PC 的 100.x，再重試
  3. 若已用 OpenVPN 等連進區網，維持區網 IPv4 即可，不必再開 Tailscale

English

Setup guides: Windows 11 · Synology · QNAP

A. Host not found

  1. Phone on home Wi‑Fi? (Cellular usually cannot reach IPv4-only home PCs)
  2. Same network? (Guest Wi‑Fi / VPN may isolate devices)
  3. Windows network profile Private?
  4. PC/NAS asleep or off?
  5. Enter IPv4 manually (ipconfig)
  6. Firewall: allow File and Printer Sharing on Private

B. Host found, login fails

  1. Use the account password, not PIN
  2. Try MicrosoftAccount\email or a dedicated local/NAS user
  3. Confirm the user is on the share permissions list

C. Logged in, folder missing

  1. Correct share name?
  2. Drill into the folder that actually holds photos
  3. Files copied into that share?

D. Browse works, upload/backup fails (read-only)

  1. Share needs Change / Read-Write
  2. On Windows, also check NTFS Security ACLs
  3. Disk full?

E. Works at home, fails on mobile data

Most IPv4-only home PCs/NAS are unreachable on cellular—that is expected. To browse away from home:

  1. Follow the Tailscale guide: install on PC and phone, same account
  2. Enter / paste the PC’s 100.x address in the app, then retry
  3. If you already use OpenVPN (or similar) into the LAN, keep the LAN IPv4—no Tailscale needed
