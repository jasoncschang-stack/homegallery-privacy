User guide / Set up home storage / Windows 11

Share a folder on Windows 11

About 10–20 minutes · for Home Gallery

Uses SMB (Windows File sharing). Follow the steps—you do not need to learn the protocol.

Before you start

  • PC runs Windows 11 on your home network
  • Phone and PC on the same home Wi‑Fi (not mobile data / guest Wi‑Fi)
  • You know your Windows username and password (set a password under Settings → Accounts → Sign-in options if you only use PIN)
  • Create a dedicated folder first, e.g. D:\FamilyPhotos (do not share the whole system drive)

Step 1: Set the network to Private

On a Public network, Windows often blocks file sharing.

  1. Open Settings → Network & internet
  2. Open Wi‑Fi (or Ethernet) → your connection
  3. Under Network profile type, choose Private

Step 2: Turn on File and printer sharing

  1. Settings → Network & internet → Advanced network settings
  2. Open Advanced sharing settings
  3. Under Private: turn on Network discovery and File and printer sharing
  4. Under All networks: turn on Password protected sharing (recommended); do not rely on Guest

Step 3: Share the folder

  1. Create e.g. D:\FamilyPhotos and put photos/videos there
  2. Right-click the folder → Properties → Sharing
  3. Advanced Sharing… → check Share this folder
  4. Note the Share name → Permissions

Step 4: Who can read / write

  1. Remove Everyone if present (recommended)
  2. Add… your Windows username → Check Names → OK
  3. Grant that user Read and Change (read/write). Upload, move/copy, saving edits, and album backup all need write access; Read alone often causes failures later. Use Read only if the phone will never write.
  4. Apply → OK

Do not share all of C:\ or your entire user profile as writable.

Step 5: Firewall

Usually fine after enabling File and printer sharing. If the app never finds the PC:

  1. Settings → Privacy & security → Windows Security → Firewall & network protection
  2. Allow an app through firewall
  3. Ensure File and Printer Sharing is allowed on Private (SMB-related; look for SMB-In in advanced rules)

Step 6: Note the name and credentials

  1. Find Device name: search Settings for About; or Settings → System → scroll to About; or Win+R → sysdm.cpl
  2. Username: local account name, or sometimes MicrosoftAccount\you@email.com
  3. Password: Windows sign-in password (not the PIN)

Step 7: Connect in Home Gallery

  1. Phone on the same home Wi‑Fi
  2. Home → Connect home storage (or More → Settings → Host connections → Add SMB host)
  3. Pick your PC from the scan (or enter IP)
  1. Enter username/password → Test connection → Save
  1. Choose the shared folder → album folder → Finish

Done checklist

  • Network profile is Private
  • Discovery + File and printer sharing On for Private
  • Folder shared; account has Read + Change (read/write)
  • Same Wi‑Fi; app opens the folder

If it fails: Troubleshooting. Also: Synology · QNAP.
