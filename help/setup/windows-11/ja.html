Windows 11でフォルダーを共有する ホームギャラリー

Home Gallery

約10～20分。これが終わった後、Home Galleryであなたの携帯電話はこのPCをホームストレージとして使うことができます。

技術名: これは SMB（Windows の「ファイル共有 / ネットワーク」機能と同じ）を使用します。プロトコルを学ぶ必要はありません—手順に従ってください。

画像: 日本語専用の画面がない場合は、英語版スクリーンショットを表示しています。

はじめる前に

  • PCはWindows 11を実行しており、自宅のネットワークに接続されています
  • 携帯とPCが同じホームWi‑Fiにある（モバイルデータ／ゲストWi‑Fiではない）
  • Windowsのユーザー名とパスワードを知っている
  • PIN/Windows Helloだけでサインインする場合は、設定 → アカウント → サインインオプションでパスワードを設定してください（電話にはパスワードが必要です）
  • まず専用の写真フォルダーを作成する、例：D:\FamilyPhotos（システム全体のドライブは共有しない）

ステップ1: ネットワークをプライベートに設定する

パブリックネットワークでは、Windowsはしばしばファイル共有をブロックします。

  1. 設定 → ネットワークとインターネット を開きます
  2. Wi‑Fi（またはイーサネット）を開く → あなたの接続
  3. ネットワーク プロファイルの種類で、プライベートを選択します

ステップ2: ファイルとプリンターの共有をオンにする

  1. 設定 → ネットワークとインターネット → 詳細ネットワーク設定
  2. 詳細な共有設定を開く
  3. プライベートの下で:
  4. ネットワーク探索: オン
  5. ファイルとプリンターの共有: 有効
  6. すべてのネットワークの下で:
  7. パスワードで保護された共有: 有効（推奨）
  8. ゲストアクセスに依存しないでください

ステップ3：フォルダーを共有する

  1. ファイルエクスプローラーで、例として D:\FamilyPhotos を作成します
  2. 写真や動画をそこに置く（または後で移動する）
  3. フォルダーを右クリック → Proパティーズ → 共有
  4. 詳細な共有… をクリックします
  5. このフォルダを共有 を確認する
  6. 共有名 を保持するか設定する（例: FamilyPhotos）— これは ホームギャラリー が共有フォルダとして表示する名前です
  7. 権限 をクリックします

ステップ4: 誰が読める / 書けるか

権限で：

  1. Everyone が存在する場合は削除する（推奨）
  2. あなたのWindowsユーザー名を追加… → 名前の確認 → OK
  3. ユーザーに 読み取り および 変更（読み書き）の権限を付与する
  4. ホームギャラリー はアップロード、移動/コピー、編集の保存、アルバムのバックアップのために書き込みアクセス権が必要です。読み取りだけだと後で失敗することがよくあります
  5. この共有に電話が書き込むことが絶対にないと確信している場合のみ、読み取りだけを使用してください
  6. 適用 → OK、ダイアログを閉じる

安全性: C:\全体やユーザープロフィール全体を書き込み可能として共有しないでください。写真フォルダのみ共有してください。

ステップ5：ファイアウォール

通常、ファイルとプリンターの共有を有効にすると問題ありません。アプリがPCをまったく見つけない場合:

  1. 設定 → プライバシーとセキュリティ → Windows セキュリティ → ファイアウォールとネットワーク保護
  2. ファイアウォールでアプリを許可する
  3. プライベート ネットワークで ファイルおよびプリンターの共有 が許可されていることを確認してください（SMB 関連; リストされている場合は詳細ルールで SMB-In を確認してください）

ステップ6: 名前と資格を記録する

  1. 以下のいずれかを使用してデバイス名（コンピュータ名）を見つけます:
  2. 設定で、端末情報またはデバイス名を検索 → 端末情報
  3. または 設定 → システム に移動し、下までスクロール → バージョン情報
  4. または Win + R → sysdm.cpl → コンピューター名 タブ
  5. ユーザー名:
  6. ローカルアカウント: 作成したアカウント名
  7. Microsoft アカウント: 時々 MicrosoftAccount\you@email.com；それがうまくいかない場合は、共有専用のローカルアカウントを作成してください
  8. パスワード：Windowsサインインのパスワード（PINではありません）

オプション: ipconfig を実行し、発見に失敗した場合にアプリで手動入力するための IPv4 アドレス (例: 192.168.1.20) を記録します。

ステップ7：Home Galleryで接続

  1. 電話は同じ家にWi‑Fi
  2. ホームギャラリー → ホーム → ホームストレージに接続 （または その他 → 設定 → ホスト接続 → SMBホストを追加）
  3. スキャンからPCを選ぶ（またはIPを入力する）
  1. ユーザー名/パスワードを入力 → 接続をテスト → 保存
  1. 共有フォルダを選択 → アルバムフォルダを選択 → 完了

アプリの詳細: user manual §4（繁体字中国語；リリース後、英語のストアリスティングはヘルプサイトを指します）。

完了チェックリスト

  • ネットワーク プロファイルはプライベートです
  • プライベート用のネットワークで、ネットワーク探索 + ファイルとプリンターの共有がオンになっています
  • フォルダーは共有されています；あなたのアカウントには 読み取り + 変更（読み書き）の権限があります
  • 電話とPCを同じWi‑Fiにする
  • アプリの接続テストが成功し、フォルダが開く

何かが失敗した場合：Troubleshooting。

短いFAQ

ノートパソコンは大丈夫？ はい、でもスリープ状態になると電話が切断されます。常時オンのPCかNASの方が良いです。

SMB 1.0 を有効にしますか？ いいえ。 ホームギャラリー と最新の Windows はより新しい SMB を使用します。

自宅以外でモバイルデータを使いますか？ 使わないでください。 ホームアルバムは同じ家のためのものですWi‑Fi。モバイル回線では、ほとんどのWindows共有にアクセスできません—これは正常です。自宅のWi‑Fiに戻ったら再び使用してください。

OneDriveと同じですか？ いいえ。これはホームネットワーク上であなたのディスクのフォルダーを読み取ります。私たちはクラウドギャラリーをホストしていません。
